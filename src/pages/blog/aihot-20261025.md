## ★ 今日最值得关注

**双框架一周内用同源内核追平 DeepInfer —— 开源推理引擎的"同帧竞赛"结束了异步差距。**

这是本期三条主线，一正两实：速度追平、延迟插件、完整性修复。

三层事实：

1. **速度追平**：vLLM 在 SemiAnalysis AgentX 基准上追平 DeepInfer，GB300 NVL72 以 P/D 分离 + Wide-EP 跑出 **954K tok/s/GPU**（单节点 **7.9×**），仅 DEP32 配置就逼近 DeepInfer EP64DP64 解码曲线；SGLang 加 Mega 内核 + SWA Bounded Replay + Engram 后，4×GB300/B300 上 prefill 达 DeepInfer **1.04×**、64×GB300 上 decode **+7.4%**。
2. **低延迟插件**：SGLang 推出 **Low-Latency Mode 插件架构**（sgl-nvidia-mega / sgl-amd-mono），DeepSeek-V4.1-Flash 解码层延迟 **96.8 → 68.4 µs（-29.3%）**，单用户 GB300 **671 → 928 tok/s（1.38×）**、AMD MI355X **332 → 516 tok/s（1.56×）**。
3. **完整性修复（可执行）**：vLLM **#60174** 修复了 v0.30/v0.31 在 DFlash2/DSpark + 前缀缓存命中后**输出损坏**的高完整性风险 bug，已并入 v0.32.0。跑 V4.1-Flash 投机 + 前缀缓存**务必升 v0.32.0+**。

> 我的判断：DeepInfer 开源后只过了一周，两个社区引擎就用同源内核把它拉回同帧——这说明 DeepSeek 把"生产级 serving 栈"这层护城河也交了出来。真正还差的是 KV/PD/负载均衡这类工程组件，而 vLLM/SGLang 恰恰在这上面补齐。结论：**别把 DeepInfer 当唯一答案，开源双框架现在 day-0/轻度优化就能拿到同档曲线。**

**性能 / 新特性**：

- 加 **Mega 内核 + SWA Bounded Replay + Engram** 后，4×GB300/B300 上 prefill 达 DeepInfer **1.04×**、64×GB300 上 decode **+7.4%**，补齐 DeepInfer 缺的生产组件。

### 原理：SGLang Low-Latency Mode 如何用 PDL 砍掉 kernel 切换

本期最值得理解的一条技术解读。

**核心做法**：SGLang Low-Latency Mode 用 **PDL（Programmatic Dependent Launch）** 让依赖 kernel 提前就绪、epilogue 经 **NVLink multicast** 直发对端 GPU；AMD 侧把解码层**塌缩为 2 个持久内核**、all-reduce **折入内核**，消掉小 kernel 切换与同步停顿。

这一条对 OpenInfer / DFlash / DSpark 低并发部署是可直接借鉴的范式——瓶颈不在单个 kernel 有多快，而在**减少 kernel launch 与跨 GPU 同步**的次数：

- **净效果**：解码层中位延迟 **-29.3%**、1M 上下文单用户解码 **43.5 → 61.1 tok/s**。
- **启示**：低并发交互负载（agent、单用户长上下文）的延迟，往往由"launch + 同步"的累计开销主导，而非计算本身。持久内核 + 依赖启动是比继续压榨单 kernel 更直接的杠杆。

### 常驻专题

**PD 分离**：vLLM **push-NIXL**（TTFT 最高 **3×**）+ 双向 KV + GB300 NVL72 **954K tok/s/GPU**；SGLang v0.5.22 PD **+27% 吞吐 / 半 p95 TTFT** + KVShard + DSpark NIXL + Mooncake；DeepInfer 缺 KV/PD/负载均衡由双框架补齐；Google **llm-d 1.0**（K8s 原生 router 拆 prefill/decode + 前缀亲和路由，Ironwood TPU 上 TTFT 降 **>85%**、吞吐 **+2.4×**）。

**架构演进**：SGLang Low-Latency（**PDL + 持久内核**）/ vLLM **Wide-EP + PD 追平 DeepInfer** / DSpark 置信度验证 + SWA Bounded Replay + Engram / **GLM-5.3 DFlash**、**Muse Spark DFlash V2 + EPD**、**Qwen3.8-Flash-Next MTP** / vLLM **#60174 完整性修复**。

## 三、AI 论文与产业热点

### 今日重点

**TacitVLA 用一格注意力 mask 证明"会思考的机器人不必想出声"**——推理收益内化进表征，四基准成功率持平显式推理而延迟最高降 **3.4×**，直接命中具身智能"聪明且快"的量产下半场痛点。

### 论文核心：TacitVLA（arXiv:2610.17540，NVIDIA / UIUC 等）

- **核心思想**：显式推理收益来自训练监督塑造的**骨干表征**，而非文本被动作专家读到；**共享训练序列 + 单格 −∞ mask** 即干净的受控实验。
- **机制**：MoT 骨干 + 流匹配动作专家；非记忆任务推理期**跳过文本生成**，记忆任务**异步写台账**；RoboMME **82.7%** / RMBench **77.5%** 刷新纪录，比无推理 **+17.1%**。
- **影响**：慢思考与高频控制共存；与 Shallow-π / RTC / 投机解码构成**端侧 VLA 降时延拼图**。

### 算子讲解：Think Token Masking（推理掩码）

`M[i,j] = −∞` 若 `j ∈ r_t`，动作专家对当前步推理 token 注意力为 0，**推理梯度照常流经骨干（监督留、条件断）**。在用：TacitVLA；同谱系 LLM 隐式 CoT（Coconut / pause token）。关键点：**零参数零开销**；坑 = 历史台账不可一刀切屏蔽。

### 性能优化：推理监督蒸馏（Latent CoT）

推理作辅助任务塑表征（`G = ∇L_task + λ∇L_reason`），动作不条件化文本。代表：TacitVLA **3.4×**；Shallow-π **364 → 110 ms**。收益：**零时延 + 满推理收益**。
