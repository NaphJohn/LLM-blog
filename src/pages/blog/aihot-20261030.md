## ★ 今日最值得关注

**低精度 KV 在本周正式从"单点技巧"变成"结构性降本"，而 SGLang 一个 CVSS 9.2 的未修补 RCE 仍悬在 v0.5.22 头上。**

两条线，一正一反：

1. **正：低精度 KV 双线成型。** vLLM `main` 新增 **Octave KV（`ROCM_OCTAVE`）原生 3-bit KV 后端**（10-26），把低精度 KV 从 NVIDIA **NVFP4 4-bit** 一路延伸到 **AMD 3-bit**。这是第一次，长上下文/多并发的 KV 成本在两大 GPU 阵营都有了"压到 4 甚至 3 位"的官方路径——长上下文部署的显存账单结构性下探。
2. **反：SGLang RCE 仍未进 release。** **CVE-2026-111391**（Dumper `eval` 注入 RCE，CVSS **9.2**）社区已提交 PR **#44205**（用 AST 白名单求值器替换 `eval`），但**只进了 `main`，没进 release**；**v0.5.22 仍受影响**。

**可执行结论**：

- 跑 SGLang 的，立刻 **`unset DUMPER_SERVER_PORT`** 并**封掉 `/dumper/configure`** 端点——这是 v0.5.22 上唯一可用的缓解，修复要等下一个 tag 或从 `main` 构建。
- 长上下文 AMD 部署，可以开始评估 Octave 3-bit KV；但**标定流程必须标准**（见原理部分），标错就是模型崩坏。

> 和 9 月那次"修复在 main、发布通道钉死"的 NVFP4 bug 是同一类问题：**"修复已存在，但 release 够不着"**。你的依赖策略里必须有一条从 `main` 构建的应急路径——这次不是输出变重复，是 RCE，危害性高一个量级。

### 原理：低精度 KV 缓存（NVFP4 4-bit / Octave 3-bit）

本期最值得理解的一条技术线。

**怎么做**：通过 **`vo_split` 拆头** + **逐层 `amax / 6.0` 标定** + **llm-compressor / compressed-tensors 存盘**，把 KV 每值从 **2 字节压到 4 甚至 3 位**。

**收益有多实**：MiniMax **M3.1** 实测**每 token KV −43.75%**，**4×B300 @ 256K** 并发 **28 → 76（约 2.7×）**。长上下文的显存账单直接砍掉近一半，多并发天花板抬升近 3 倍。

**代价同样明确**：标定对则**近无损**，标错则**模型崩坏**。这不是"调个参数"的事，是**必须走标准标定流程 + 做精度回归**的硬工程。

> 我的判断：低精度 KV 正在从"少数人的黑魔法"变成"两大阵营都认的默认选项"。它一旦默认开，长上下文推理的 economics 就变了——但前提是你的标定管线配得上这份信任。团队里如果还没有人专门盯 KV 量化精度回归，现在是时候指定一个了。

## 三、AI 论文与产业热点

**今日重点**：Hugging Face 的 **SmolVLA** 用 **0.45B 参数 + 全社区数据**打平 10 倍体量 VLA（LIBERO **87.3 vs π0 86.0**），宣告「小而专」路线成立，恰逢**宇树 / 智元财报创新日**与 **HF 旗下 Microduck 出圈**——具身智能「**产业上量 × 技术降本**」双曲线共振。

### 论文核心：SmolVLA

**SmolVLA**（Hugging Face / 索邦 / valeo.ai，arXiv:2506.01844，2025-06，开源）——0.45B「平民 VLA」：**SmolVLM-2** 骨干 + ~100M 流匹配动作专家。

- **层截断**：动作专家只读 VLM 前 **16 / 32 层**（78.5 vs 80.3，截断优于隔层跳）。
- **64 视觉 token / 帧** + CA / 因果 SA 交替动作专家（**85.5 vs 纯 CA 79.0**）。
- **全社区数据**：481 集 / 2.29 万轨迹 / 1060 万帧（SO-100 / 101）。
- **异步推理**：9.7s vs 13.75s（**+29.5%**）、60 秒 19 vs 9 次（**~2.1×**）。
- **影响**：LeRobot 社区路线成为开源具身事实标准；端侧轻量 VLA = 机器人大脑降本关键环节。

### 算子讲解：Logit Soft-Capping（Gemma 2）

**tanh 软截断**压 logits 上界（注意力 **50** / 输出 **30**），梯度 `sech² ≤ 1` 平滑，**BF16 免 FP32 upcast**。Gemma 3 弃用改 **QK-Norm**；姊妹技术 **QK-Clip**（MuonClip τ=100）。具身关联：端侧 BF16 微调 VLA 的**零成本稳定器**。

### 性能优化：GPTQ / AWQ 权重-only 量化

**算法内核角度**——GPTQ **Hessian 误差补偿**（175B 约 4 GPU 时）/ AWQ **1% 显著通道缩放**；**Marlin W4A16** 解码 **3.87×~5.7×**。具身关联：0.45B~3B VLA 量化上 **Jetson**，与 **Helix 双系统 / TeaCache** 构成端侧三件套。
