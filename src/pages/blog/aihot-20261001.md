## ★ 今日最值得关注

**vLLM 于 09-30 切出 v0.31.0rc1/rc2 发布线（CI/Mamba 修复为主、特性集待 rc3+），稳定锚点仍是承载 CVE-2026-93436 修复的 v0.30.0；SGLang main 同日推进两条线——#41344 把 FA4 引进 ViT 视觉塔、#40826 候选 token 打分校准（与 DFlash2 候选选择器同构）、#41818 把注意力数据并行拆成 --attn-dp-size 独立旋钮；论文侧 Skild S1 把 LLM 的「上下文学习」搬进机器人控制，一段人类视频零微调执行 10 分钟新任务（66% vs 9% 步成功率）。** 今天最该进你「升不升」决策表的，是 vLLM 把精力铺在 v0.31 rc 的 CI/Mamba 收尾、而 SGLang 却在 main 上把多模态与投机解码两个结构件同时往前推。

三层事实：

1. **版本是什么**：vLLM 主线 09-30 切出 **v0.31.0rc1/rc2**（updateshub 镜像），目前以 **CI/Mamba 修复** 为主（`#59118`、Mamba prefill checkpoint 修复），特性集待 **rc3+**；**v0.30.0（09-21/22，762 commits / 315 贡献者）仍是稳定锚点**——承载 CVE-2026-93436 修复、Fast Start、HiSparse、双键水印、MRV2 图冻结，Model Runner V1 已弃用、v0.32 移除。
2. **SGLang main 两条线**：① **#41344（09-27）把 FA4 引进 ViT 视觉塔**（SM100/SM103）——VLM 推理里视觉塔在 prefill 阶段做图像 patch 自注意力，是图像输入的固定开销，FA4 把这块延迟与显存再压一层；② **#40826（09-24）候选 token 打分与校准**，与本人 OpenInfer/DFlash2 候选选择器同构，直接利好投机解码接受率；③ **#41818（09-30）新增 --attn-dp-size 并弃用 --enable-dp-attention**，注意力数据并行成独立旋钮，利于 PD 分离长上下文 decode 吞吐。
3. **机器人「上下文学习」**：Skild S1 用视频演示替代文本指令，把机器人策略训成元学习器——一段人类视频 ≈ 380 个 post-training episodes，内部基准未见任务 **66% 步成功 vs 语言提示 VLA 9%**。

**可执行结论**：生产 PD 继续锚定 **v0.30.0**（≤0.29.0 仍受 CVE-2026-93436 内存耗尽影响，CVSS 8.7）；v0.31 等 **rc3+** 再看特性集；想试 SGLang 新结构件从 main 构建、盯 **v0.5.21** 候选；机器人侧把「视频 prompt + 通用大脑」当成 VLA 之外的新路线看，但 Skild 暂无量产权重/论文/API，66% 为有辅助的每步成功率，数据经挑选。

> 值得强调：SGLang 把 FA4 引进 ViT 视觉塔，和 Step-3.7-Flash 1.8B 视觉塔、Step 5 多模态路线是同一句话——**多模态推理的 prefill 瓶颈正在从「模型结构」挪到「视觉塔的注意力 kernel 效率」**。本人 OpenInfer/DFlash 的「复用已算能力」逻辑，今天在 #40826 候选打分上又见一次同构：候选选择器不是装饰，它直接决定 E[L]（接受长度），而 E[L] 才是投机解码真金白银的吞吐账。

## 二、vLLM & SGLang 社区跟踪

**版本状态**：窗口内 **vLLM 主线切出 v0.31.0rc1/rc2（09-30），仍以 v0.30.0（762 commits / 315 贡献者）为稳定锚点**；SGLang **最新稳定版仍为 v0.5.20（09-18，713 PRs / 237 贡献者），v0.5.21 未发**，main 持续活跃（FA4 ViT #41344、候选打分 #40826、--attn-dp-size #41818、transformers bump 5.17.0）。

**版本 / 安全落地**：

- **版本**：`v0.31.0rc1/rc2`（09-30）以 **CI/Mamba 修复** 为主（`#59118`、Mamba prefill checkpoint 修复），特性集待 **rc3+**；`v0.30.0`（09-21/22，762 commits / 315 贡献者）仍为 **PD 分离生产推荐升级目标**——承载 **CVE-2026-93436** 修复（PD 分离下被拒请求 KV metadata 未释放致内存耗尽，CVSS 8.7，修复 `#55677`）、Fast Start、HiSparse、双键水印、MRV2 图冻结；Model Runner V1 已弃用、v0.32 移除。

### SGLang（v0.5.20 · FA4 ViT + 候选打分 + --attn-dp-size）

**新特性 / 架构演进**：

- **#41818（09-30）**：新增 **`--attn-dp-size`** 并弃用 `--enable-dp-attention`——注意力数据并行成独立旋钮，利于 PD 分离长上下文 decode 吞吐。
- **#41344（09-27）**：把 **FA4（FlashAttention-4）引入 ViT 视觉塔**（SM100/SM103），多模态图像编码吞吐提升。
- **#40826（09-24）**：**候选 token 打分与校准**，与 DFlash2 候选选择器同构，利好投机解码接受率。
- **#39012（09-30）**：bump **transformers 到 5.17.0**；稳定版仍 **v0.5.20**，v0.5.21 未发。

### 原理：FA4 进 ViT 视觉塔（多模态 prefill 瓶颈搬家）

- **FA4（FlashAttention-4）用于 ViT 视觉塔**：VLM 推理中，视觉塔在 **prefill 阶段** 对图像 patch 做自注意力，是图像输入的**固定开销**；FA4 进一步降延迟、提显存效率，使**多图 / 高分辨率输入不再成为 prefill 瓶颈**——与 Step-3.7-Flash 1.8B 视觉塔、Step 5 多模态路线同方向（视觉塔注意力 kernel 效率，而非模型结构，成为多模态吞吐的新天花板）。

> 我的判断：SGLang 把 FA4 引进视觉塔，说明多模态推理的工程重心正在从「堆视觉塔参数量」转向「视觉塔注意力的 kernel 效率」——这是 VLM 在 prefill 阶段能不能吃下高分辨率多图的真问题。而对投机解码更实质的推进是 #40826 候选打分：它和本人 DFlash2 候选选择器同构，证明「候选怎么排、怎么校准」比「候选由谁生成」更能直接撬动接受长度。

## 三、AI 论文与产业热点

### 今日重点（1 句）

**Skild S1 把 LLM 的「上下文学习」搬进机器人控制——一段人类视频 prompt、零 fine-tune 即可执行 10 分钟新任务（内部基准未见任务 66% 步成功 vs 语言提示 VLA 9%，一个视频 ≈ 380 episodes），标志机器人学习可能走出「每任务都要 fine-tune」的 BERT 时代；算子侧 SoftMoE 用 LapSum 软 top-k 让路由可梯度优化、SonicMoE 把高粒度稀疏 MoE 的反向显存 −45%，共同把 MoE VLA 端侧部署往前推；产业侧特斯拉 Optimus 年底目标 1.5 万台、周产爬坡 1000→2500，智元累计下线 1.5 万台，宇树 IPO 在即、R1 定价 3.99 万。**

### 论文核心（Skild S1 · In-Context Learning for Robotics）

- **一句话定位**：把 LLM 的「上下文学习（in-context learning）」范式搬进机器人——用**视频演示**替代文本指令，把机器人策略训成**元学习器**，一段视频即可唤起对新任务的执行能力，无需逐任务 fine-tune。
- **核心做法**：预训练混合**遥操作 / UMI 手套 / 第一人称视频 / 仿真**四类数据；内部基准**未见任务 66% 步成功**（有辅助）vs **语言提示 VLA 9%**；一个视频 ≈ **380 个 post-training episodes**——视频 prompt 的数据效率远胜逐任务训练。
- **影响**：若数据规模持续放大，机器人部署经济模型可能从「**每任务训练专家**」转向「**通用大脑 + 视频 prompt**」，类比 LLM 从 BERT 到 GPT-3。
- **局限**：无公开权重 / 论文 / API，数据为 Skild 内部测试、演示经挑选，**66% 为有辅助的每步成功率**——先当路线信号、别当量产基准。

### 算子讲解：SoftMoE（软 top-k 路由，arXiv:2606.17952）

- **定位**：用 **LapSum 软 top-k** 替代硬 top-k，使**路由可梯度优化**——每层激活专家数 `k_l = K·softmax(α_l)` 变成可学习参数，路由不再离散不可导。
- **在用 / 相关**：与 **DeepSeek V4 / Qwen3-MoE / MiniMax 密集 MoE** 路线直接相关；**端侧 VLA** 可借其动态减少激活专家、降时延（激活专家数随层可学，而非固定 K）。

### 性能优化：SonicMoE（MoE IO/Tile 感知加速，arXiv:2512.14080）

- **定位**：针对**高粒度 + 高稀疏 MoE** 的激活内存膨胀与 GEMM 填充浪费——内存高效反向传播 **−45%**、**64 H100 日训练 213B token**、Blackwell 前向 **+25%** / 反向 **+15%**。
- **同族**：与 **MegaBlocks / DeepGEMM / SGLang / vLLM fused MoE kernel** 同族，**利好 MoE VLA 端侧部署**（稀疏激活的显存与计算浪费被 Tile 级摊平）。

### 产业热点（具身公司 / 产业链速递 · 置顶）

- **【具身】Skild S1**：发布并与 **ABB / UR / MiR / 富士康** 合作 → 映射 **绿的 688017 / 三花 002050 / 拓普 601689 / 机器人 ETF 562500**。
- **【具身】特斯拉 Optimus**：年底目标 **1.5 万台**、周产爬坡 **1000→2500** → 拓普 601689 / 三花 002050 / 绿的 688017 / 均胜 600699 / 562500。
- **【具身】智元**：累计下线 **1.5 万台** → 上纬新材 **688585**。
- **【具身】优必选 09880**：再签 **2.5 亿** Walker S2 订单；**【具身】宇树 688836**：IPO 在即、**R1 定价 3.99 万**。
