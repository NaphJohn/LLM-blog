## ★ 今日最值得关注

**本期最关键的一条是 vLLM 合并了 FLy 有损投机验证器（#53987，10-19）——这是「用一点分布保真度换草稿接受率」路线第一次进主流引擎主干，解码最高 +31%（AMD）/ +27%（NVIDIA）；同期 vLLM 切出 v0.32.1rc0（RL 权重零磁盘直推），SGLang 仍停在 v0.5.22 且 CVE-2026-111391 仍未修复。论文侧 EvoVLA 用 Gemini 2.5 Pro 造的硬负样本把 VLA「阶段幻觉」从 38.5% 压到 14.8%——具身可靠性补齐最后一块拼图。**

三层事实：

1. **版本与安全（vLLM 小版本 RC + SGLang 稳但带洞）**：**vLLM 切 v0.32.1rc0（10-18）** 主要把 RL trainer 的 HTTP 权重传输协议文档化（#62267，RL 热更新权重零磁盘直推，需配 mTLS）；**稳定版仍为 v0.32.0（814 commits / 363 贡献者）**。**SGLang 稳定版仍 v0.5.22（10-16），窗口内无 v0.5.23**；更关键的是 **CVE-2026-111391（Dumper 调试端点表达式求值注入，0.5.10–0.5.22，CVSS 8.1）仍无修复版**——生产务必关 Dumper。
2. **架构演进（有损投机验证器进主干）**：**FLy #53987 合并（10-19）**——标准拒绝采样要求分布严格一致（无损），FLy 放宽：目标 top-3 熵≥0.3（不确定）且其后 W 个草稿 token 常规验证通过时，容错接受一个孤立被拒草稿 token，换更高接受率/吞吐；**另修 MTP + thinking_token_budget 死 bug #58231**（reasoning 模型+投机+top_p<1 会持续吐 token 0、吞吐跌约 3×，此类部署必升）。
3. **论文信号**：**EvoVLA（北大唐浩组，arXiv:2511.16166）用 Gemini 2.5 Pro 切 74 阶段 + 生成硬负样本三元组对比学习，把长时程「阶段幻觉」（假装完成骗过 VLM 评估器）从 38.5% 压到 14.8%**，真机成功率 54.6%（+11pp），与 FD-VLA/SVA/StableVLA/GeoVLA 构成 VLA 可靠性五部曲。

**可执行结论**：生产继续锁 **v0.32.0（vLLM）/ v0.5.22（SGLang）**，但两类部署必须升：跑 reasoning+投机+top_p<1 的立刻上含 #58231 的版本；FLy 默认开前先确认 eval/对齐评测关掉（最坏精度约 96.3%）。SGLang 侧把 Dumper 端点彻底关掉再说。EvoVLA 的「LLM-as-Teacher 出错题集反哺 RL」范式可迁移到本人车端/具身 VLA 路线。

> 值得强调：FLy 把「有损投机验证」从 DFlash/DSpark 的块级/自适应验证赛道，正式拉进 vLLM 主干——与本人 OpenInfer/Qwen3-4B DSpark 同处一条线。它的代价是分布不再严格保真（最坏精度约 96.3%），所以 **eval 与对齐评测一定要关 FLy**；生产吞吐红利（最高 +31%）只在"分布宽松可接受"的场景吃。

## 二、vLLM & SGLang 社区跟踪

**版本状态**：本期 **vLLM 切 v0.32.1rc0（小版本 RC）+ 稳定版 v0.32.0 保持，SGLang 稳定版 v0.5.22 保持（无 v0.5.23）**——主线在「有损投机验证器进主干 + RL 零磁盘权重 + PD 双向 KV + 安全补洞」方向收口，而非大版本号刷新。

### vLLM（v0.32.0 稳定版保持 + v0.32.1rc0 RL 增量）

**版本 / 安全落地**：

- **版本**：**稳定版仍 v0.32.0（10-18，814 commits / 363 贡献者）**，窗口内无新稳定 tag；主线 10-18 切 v0.32.1rc0 主做 RL trainer HTTP 权重传输协议文档化（#62267）。影响：生产仍以 **v0.32.0** 为目标，升级先回归 #58231 修复。
- **重要 PR（有损投机）**：**FLy 有损投机验证器 #53987（10-19 合并）**——目标 top-3 熵≥0.3 容错接受孤立被拒草稿 token，AMD 1.055–1.310×、NVIDIA 1.041–1.273× 解码提速，eval 与对齐评测应关闭。
- **Bug 修复（必升）**：**MTP + thinking_token_budget 死 bug #58231（10-19）**——reasoning 模型 + 投机解码 + top_p<1 会持续吐 token 0、吞吐跌约 3×，此类部署必须升。
- **PD 分离（多轮 agent 利器）**：**Push-based NIXL connector + 双向 KV 技术博客（10-19）**，多轮 agentic Qwen3-32B TTFT 1.6×、GLM-5-FP8 3.3×。

### SGLang（v0.5.22 · 版本号坐实 + main decode-dispatch-limit）

**新特性（已发版确认 + main 近窗）**：

- **v0.5.22（10-16，Latest）**：稳定版坐实，窗口内无 v0.5.23；main 10-19 合并 **#44402**。
- **main 近窗**：**sgl-router 新增 --decode-dispatch-limit N（#44402）**，DeepSeek-V4-Pro 上 decode TPOT 降最多 7.5%——PD 弹性调优新旋钮。
- **安全（务必处理）**：**CVE-2026-111391（Dumper 调试端点表达式求值注入，0.5.10–0.5.22，CVSS 8.1）仍无修复版**——生产务必关闭 Dumper 调试端点。

### 原理：FLy（Faithful-yet-Lossy，#53987）——「目标不确定处让一步」的有损投机验证

- **做法**：标准拒绝采样要求草稿分布与目标分布严格一致（无损），FLy 放宽——当目标在生成某 token 时 top-3 熵≥0.3（即模型本身就不确定），且其后 W 个草稿 token 都通过常规验证时，容错接受**这一个**孤立被拒草稿 token。
- **收益**：更高草稿接受率 → 更高解码吞吐，实测 AMD 1.055–1.310×、NVIDIA 1.041–1.273×（最高 +31%）；代价是分布不再严格保真，**最坏精度约 96.3%**，故 **eval 与对齐评测必须关闭 FLy**。
- **定位**：与 OpenInfer/DFlash/DSpark 同处**块级 / 自适应验证**赛道，可作本人 Qwen3-4B 验证器对照范式——"哪里让一步、让多少"是可调旋钮，而非一刀切无损。

> 我的判断：本期版本号稳（v0.32.0 / v0.5.22），增量集中在「有损投机验证器进主干（#53987）+ MTP thinking-budget 修复（#58231）+ RL 零磁盘权重（#62267）+ PD 双向 KV」四条线。FLy 把"分布宽松换吞吐"做成默认可选，是对的工程取舍，但**保真度底线必须由评测开关守住**。SGLang 这边没有新版本，CVE-2026-111391 未修是悬在头上的安全债，关 Dumper 是当下唯一解。

### 常驻专题

**PD 分离**：vLLM push-NIXL 稳定 + 双向 KV（多轮 1.6–3.3× TTFT）；SGLang #44402 decode-dispatch-limit（−7.5% TPOT）；GPUStack 配方 vllm-nixl / sglang-mooncake(preferred) / sglang-nixl。

**架构演进**：投机解码成两引擎共同主轴（vLLM FLy + MTP thinking-budget 修复；SGLang decode-dispatch-limit）；决策端点（/v1/systemone + Clef）成标配；低精度 KV/量化继续铺开。

**PyTorch vs transformers**：窗口内无"脱离 transformers"PR；vLLM 延续把推理解析器规范读入 HF response_template、Transformers 后端补视频；边界重分层延续。

**Step 适配**：Step 5 双框架 day-1 对齐（官方 Docker + cookbook），差异在 KV offload 与首启 FlashInfer 编译；vLLM 官方支持 PR **#61727 仍在草稿态**，合并后将进稳定。

## 三、AI 论文与产业热点

### 今日重点（1 句）

**EvoVLA（北大唐浩组，arXiv:2511.16166）用 Gemini 2.5 Pro 切 74 阶段 + 生成硬负样本三元组对比学习，把长时程操作「阶段幻觉」（假装完成骗过 VLA 评估器）从 38.5% 压到 14.8%、样本效率 1.5×、真机成功率 54.6%（+11pp），与 FD-VLA/SVA/StableVLA/GeoVLA 构成 VLA 可靠性五部曲；算子 FSQ 根治 VQ-VAE 码本坍塌、KV 分层卸载（热 HBM/温 DRAM/冷 NVMe）长前缀 TTFT 降 5~10×；产业面沙利文称 2026H1 全球人形销量 3.6 万台、收入前五全中国。**

### 论文核心（EvoVLA · arXiv:2511.16166）

- **一句话定位**：**治长时程操作中的「阶段幻觉」**——模型假装完成某阶段、骗过 VLA 评估器（如把"已抓取"报成完成但实际没抓稳），是上岗前最隐蔽的可靠性缺口。
- **做法**：① **SAR 阶段对齐奖励**：Gemini 2.5 Pro 切分 74 阶段 + 生成**硬负样本三元组**（真完成 / 假完成 / 边界）对比学习 + 时间平滑；② **POE 位姿探索**：好奇心锚定夹爪-物体**相对位姿**而非像素；③ **长程记忆**：Top-K 检索 + 门控融合。
- **结果 / 影响**：Discoverse-L 69.2%（+10.2pp）、幻觉率 38.5→14.8、样本效率 1.5×、真机 54.6%（+11pp）；「LLM-as-Teacher 出错题集反哺 RL」范式——与本人车端/具身 VLA 路线同构，可先把"硬负样本出题"接进训练闭环。

### 算子讲解：FSQ（Finite Scalar Quantization, ICLR 2024）

- **定位**：逐维电平 round + 混合进制索引 + 直通梯度，**零码本、零辅助损失**根治 VQ-VAE 码本坍塌。
- **关键点**：MAGVIT-v2 / VideoPoet tokenizer 候选、VLA 动作离散化（FAST 系）底座；坑 = 电平选 [8,6,5] 量级、低维用 FSQ、高维换 LFQ。

### 性能优化：KV Cache 分层卸载

- **定位**：热 HBM / 温 DRAM / 冷 NVMe + 块化异步预取；代表 Mooncake / LMCache / SGLang 分层缓存。
- **收益**：长前缀命中 TTFT 降 5~10×、并发数倍增；与 KV 级联召回分工（**读什么 vs 放哪里**）；具身含义 = 多机器人并发推理降本底座。
