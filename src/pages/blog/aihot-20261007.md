## ★ 今日最值得关注

**本期窗口内无新正式版本（vLLM v0.31.0 / SGLang v0.5.21 保持），但两家主线分支都在「投机解码硬化」方向密集收口——vLLM MRV2 固定边界投机补 sampling-mask replay、修复混合 Mamba 与 DSpark 越界；SGLang #42297 落地区块级验证路径，与 DFlash/DSpark 块扩散同源，验证回退更少、接受率更高；国产侧最大事件为阶跃 Step 5 Preview 定档 10-15 开源（倒计时 8 天）。其中最硬的一条：SGLang #42297 块验证按块接受更长 draft 前缀（需存 draft probability + proposal sampling），相比 token-wise rejection sampling 一旦某位置拒绝则其后 draft 全废——对本人 OpenInfer/Qwen3-4B DFlash 是现成可复用的「降每步 draft 开销、提接受率」模板，但正确性更依赖状态固化是否完整。**

三层事实：

1. **版本与安全（无新 tag）**：**vLLM 稳定版仍为 v0.31.0（10-05，717 commits / 307 人），窗口内无新 tag**；**SGLang 稳定版仍为 v0.5.21（10-02，779 PRs / 227 贡献者），无 v0.5.22**。影响：生产稳定锚不变（vLLM v0.31.0 / SGLang v0.5.21），本期是「主线硬化收口」而非「版本号刷新」的故事。
2. **投机解码硬化（同走一条线）**：**vLLM MRV2 固定边界投机解码新增 sampling-mask replay**（为 accepted/recovered/bonus token 返回 target support set，扩展 MTP/EAGLE/dFlash/dSpark/draft model 服务能力，混合批次下可正确回放采样支撑集、RL rollout 更安全）+ 修复混合 Mamba（GraniteMoeHybrid/FalconH1/Zamba2）spec 下 MambaSpec 断言失败 + 修复 DSpark `sample_from_anchor=false` 的 KV slot 越界（改预留 N+1，与 OpenInfer/DSpark 主线直接相关）；**SGLang #42297（10-05）opt-in 块级验证**（块接受更长 prefix、保持 target 采样语义）。两边同走「投机解码硬化」。
3. **论文信号**：**ForeAct3D（arXiv:2610.04607）把世界模型塞进 VLA 训练期**——用可学习几何查询预测动作打完后的 3D 语义未来，再用背景静态性/实例级刚性/腕部相机锚定三道物理约束收紧，**推理时整支丢弃、零额外开销**；配套 **Token Merging（ToMe，ICLR 2023）视觉 token 合并**（ViT-L 图像吞吐 2×、精度仅掉 0.2~0.3%）与 **Real-Time Chunking 实时分块**（π0.6 真机 0.82→0.93、时延 135ms→108ms）两张落地底牌。

**可执行结论**：生产继续锁 **v0.31.0（vLLM）/ v0.5.21（SGLang）**，本期先把 #42297 块验证 vs token-wise 接受率差异、sampling-mask replay 在混合批次下的回放正确性各 benchmark 一遍；Step 5 权重 10-15 落地后用 `--reasoning-parser stepfun` 双框架直接跑。

## 二、vLLM & SGLang 社区跟踪

**版本状态**：窗口内 **vLLM v0.31.0（10-05，717 commits / 307 人）/ SGLang v0.5.21（10-02，779 PRs / 227 贡献者）双双保持，无新正式版本**——本期主线在「投机解码硬化」方向密集收口，而非版本号刷新。

### vLLM（v0.31.0 稳定版保持 + main 投机解码硬化）

**版本 / 安全落地**：

- **版本**：**v0.31.0 稳定版保持（10-05，717 commits / 307 人）**，窗口内无新 tag；main 10-07 仍以 spec decode 硬化为主。影响：生产仍以 **v0.31.0** 为目标，升级先回归 MRV2+投机解码组合。
- **重要 PR（硬化）**：**MRV2 fixed-boundary 投机解码新增 sampling-mask replay**——为 accepted/recovered/bonus token 返回 target support set，扩展 MTP/EAGLE/dFlash/dSpark/draft model 服务能力；混合批次下 spec decode 可正确回放采样支撑集，**RL rollout 更安全**。
- **Bug 修复**：修复混合 **Mamba（GraniteMoeHybrid/FalconH1/Zamba2）在 spec decode 下 MambaSpec 断言失败**；修复 **DSpark `sample_from_anchor=false` 的 KV slot 越界（改预留 N+1）**——混合 SSM + DSpark 可正确启动，与 **OpenInfer/DSpark 主线直接相关**。
- **社区分支**：vLLM-metal（Apple Silicon）**#931/#959 多模态禁用时保留 selective logits 并把显存让给 KV cache**——纯文本服务可扩 KV（属分支非主线）。

### SGLang（v0.5.21 · 版本号坐实 + main 块验证路径）

**新特性（已发版确认 + main 近窗）**：

- **v0.5.21（10-02，779 PRs / 227 贡献者，Latest）**：前缀缓存默认 Rust 核心（#39627）、PD 角色热切换 GA（#28403）、DSv4.1 长提示 TTFT +22%（#40352）、Kimi K3 PD prefill +20.6%（#40045）、新增 Decisions/Score API。
- **main 近窗**：**#42297（10-05）opt-in 块级验证**——实现块级验证路径，相比 token-wise rejection sampling 可在保持 target 采样语义下接受更长 draft 前缀；性能侧 **候选 token 打分校准 #40826、--attn-dp-size 一等化 #41818** 延续。
- **社区讨论**：sgl-router 均衡策略改进（#42545）+ hybrid Mamba indexer host pool（#40915，HiCache 宿主池扩展）；延续 /v1/decisions + /v1/score，社区「决策模型/System One」热潮下 **/v1/systemone 兼容 TypeSafe SDK**，普通聊天模型转打分/决策模型 100ms 级。

### 原理：SGLang #42297——块级验证（按块接受更长 draft 前缀）

- **做法**：传统 **token-wise rejection 一旦某位置拒绝则其后 draft 全废**；块验证**按块接受更长前缀**（需存 draft probability + proposal sampling），与 **DFlash（块扩散）/DSpark（并行前向 D 个草稿）天然契合**，验证回退更少。
- **收益**：spec decode 接受率更高、吞吐更好；建议优先 **benchmark 块验证 vs token-wise 接受率差异**——对本人 OpenInfer/DFlash 是直接可复用的「降每步 draft 开销、稳接受率」模板；代价是正确性依赖状态固化是否完整（回看 vLLM #56158 的雷）。

> 我的判断：本期没有版本号刷新，但 vLLM 的 sampling-mask replay + SGLang 的 #42297 块验证是同一方向的「投机解码硬化」双收口——把验收从 token 级推进到块级、把采样支撑集在混合批次下正确回放。与本人 OpenInfer/DFlash/DSpark 同源：核心都是「降每步 draft 开销、让 draft 接受更长、提端到端 decode 吞吐」。旧路径（FULL/token-wise）在长上下文高并发下仍会咬人，所以状态固化完整性优先级依旧高。

### 论文核心（ForeAct3D · arXiv:2610.04607）

- **一句话定位**：**把世界模型塞进 VLA 训练期**——用可学习几何查询预测「自己这套动作打完之后的 3D 语义未来」，再用三道物理约束（背景静态性、实例级刚性、腕部相机锚定）收紧它；**推理时整支分支丢弃、零额外开销**。
- **做法**：几何查询解码深度/语义分割/相机位姿，像素经 `P=T_cam·K⁻¹·[u,v,1]ᵀ·D` 提升为 3D 点；未来分支额外以动作分块为条件，实现 policy-grounded；物理一致性闭包：背景不动、同实例服从同一刚体变换 `p'=R·p+t`、腕部相机位姿由动作经 SE(3) 积分给出不许瞎猜。
- **结果（自报）**：无机器人预训练 LIBERO 98.3%、CALVIN 任务长度 3.73、真机成功率 6.7%→37.8%。
- **影响**：世界模型谱系收敛到**第三种形态（结构化 3D 语义预测）**，比生成式视频便宜一个量级；可迁移范式 =「训练期加物理先验、推理期零开销」。

### 算子讲解：Token Merging（ToMe · arXiv:2210.09461）

- **定位**：**每层用二分软匹配合并相似 token**，按 size 加权平均 `z_m=(s_i·z_i+s_j·z_j)/(s_i+s_j)`；facebookresearch/ToMe 可 patch 进 timm/MAE/SWAG，ToMeSD 加速 Stable Diffusion。
- **关键点**：相比 pruning 是「合并」而非「丢弃」，信息保留更完整；**Qwen3-VL / DeepSeek-VL2 / InternVL / MiniMax-VL / GLM-4.5V 的视觉 token 压缩同属该谱系**；ViT-L 图像吞吐 2×、视频 2.2×，精度仅掉 0.2~0.3%，注意力算力近似降到 1/4。

### 性能优化：Real-Time Chunking（RTC · arXiv:2506.07339 + 2512.05964）

- **定位**：把动作块切换形式化为**图像补全**——已承诺执行的前 d 个动作是「不能改的像素」，其余重新生成。
- **收益**：**π0.6 真机成功率 0.82→0.93、耗时 143s→112s、端到端时延 135ms→108ms**，注入 200ms 延迟仍不掉点——把「长 horizon 重规划」压成实时可负担。
