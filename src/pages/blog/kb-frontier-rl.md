## 1. OAT：从"成功之流"溯源 Agent 失败（arXiv:2607.12747）

- **问题**：长程 Agent 出错时，往往只知道"最后结果错了"，不知道"哪一步走偏"。
- **做法**：用无监督、轻量的方式（**神经微分方程 NCDE**）从**成功轨迹**反学"失败发生在哪一步"，无需人工标注失败样本。
- **优势**：比行为监控**更早发现**轨迹走偏。
- **具身映射**：可迁移到"机器人操作失误定位"——提升自主系统的可调试性，是具身智能投资主线里"机器人自主决策"可靠化的关键一环。

## 2. Ring-Zero：Zero-RL 推到 1T 参数（人大×蚂蚁, 2607.12395）

- **核心发现**：把 Zero-RL（无需 SFT 冷启动、直接从 RL 学推理）推到 **1T 参数**规模时，**高级思维策略自发涌现**。
- **意义**：进一步验证"规模 + 规则化奖励"能逼出复杂推理，弱化对海量 SFT 数据的依赖。

## 3. SPS：状态-预测分离（康奈尔×哈佛, 2607.01218）

- **核心**：把"状态表征"与"未来预测"解耦训练，训练效率 **2.6×**。
- **意义**：表征与预测解耦后更容易复用与缩放，是高效世界模型/预言机的工程思路。

## 4. HiLS-Attention：8K 训练外推 4M（腾讯混元, 2607.02980）

- **核心**：一套注意力改进，使模型在 **8K 上下文训练**下可外推到 **4M**，prefill 提速 **13.5×**；已开源。
- **意义**：长上下文"训短用长"的性价比路线，直接利好超长文档/代码/多模态序列场景。

## 5. 探索悖论 RL（字节 Seed×MSU, 2607.06987）

- **核心**：修正探索中的**重要性采样偏差**，让 RL 探索更高效、更稳。
- **意义**：细节但重要——长程推理 RL 的熵崩溃/探索不足是常见坑，此工作给出系统性修正。

## 6. AMVL：潜空间连续推理（上交×蚂蚁, 2607.00461）

- **核心**：在**潜空间**做连续推理，BLINK 基准 **+10.83**。
- **意义**：呼应"扩散/连续表征做推理"的路线（也见 DFlash/DFlash 类块扩散草稿），与纯离散 token 推理互补。

## 7. 实践启示

- 这组工作共同指向：**推理能力正从"堆参数"转向"更好的训练信号 + 更好的长上下文/潜空间表征"**。
- 对投资：推理效率（OAT 可调试性、SPS/HiLS 效率、AMVL 潜空间）的进步，是决定大模型服务成本与具身端侧可行性的底层变量。
