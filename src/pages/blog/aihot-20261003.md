## ★ 今日最值得关注

**SGLang v0.5.21 于 10-02 正式发布（779 PRs / 227 贡献者），把前缀缓存默认下沉到 Rust 核心、PD 角色热切换 GA、DeepSeek-V4.1 长提示首 token +22%，是窗口内唯一正式大版本；而 vLLM 仍停在 v0.31.0rc3（Model Runner V2 线，rc1/rc2/rc3 全是 CI/bugfix），稳定锚还是 v0.30.0——同一帧里「谁在交付、谁在候选」一目了然。**

三层事实：

1. **版本与事件**：SGLang **v0.5.21（10-02，779 PRs / 227 贡献者，Latest）**——窗口内唯一正式大版本，升级即白嫖多项默认能力：前缀缓存默认跑在 Rust 核心（#39627）、PD 实例 prefill↔decode 即时切换无需重启（#28403 今 GA）、DeepSeek-V4.1 长提示首 token +22%（#40352）、Kimi K3 PD prefill 吞吐 +20.6%（#40045），外加 day-0 新模型十款（DeepSeek-V4.1 Flash、GigaChat 3.5、Qwen-Image 2.1、FLUX 3 Action 等）。
2. **vLLM 路线**：**v0.31.0rc3（约 10-01）仅 Model Runner V2 支持 randomized dummy inputs（#58411）**，rc1/rc2/rc3 全程 CI/bugfix，特性集待 rc3+；稳定锚仍是 **v0.30.0（09-22，载 CVE-2026-93436 修复/Fast Start/HiSparse/双键水印/MRV2 图冻结）**；补丁线 v0.30.1rc0（09-23）含 AMD MI355 dense NVFP4 + MoRI kernel 镜像（#58281）。结论：生产继续锁 v0.30.0。
3. **论文信号**：Google DeepMind **Gemini Robotics 2** 把机器人 VLA 推向「从脚到指尖」的整身控制 + 跨本体软件层平台化；算子 **DyT** 用可学习 tanh 替掉归一化层（LLaMA 8B 训练省 42.2%、推理省 52.4%），**AdaEAGLE** 给 EAGLE 加草稿长度预测器做自适应投机解码（1.62× 无损）。

**可执行结论**：想立刻吃到默认能力红利，升 **SGLang v0.5.21**；vLLM 生产继续锚 **v0.30.0**（PD 分离须 ≥0.30.0 才有 CVE-2026-93436 修复）；Step 5 权重 10-15 才开源、距今天 12 天，按 Step-3.7-Flash 双框架成熟路径备部署。

> 值得强调：SGLang #39627 把前缀缓存从 Python 层下沉到 scheduler 的 Rust 核心，消的是高 QPS 下「缓存命中查询/插入/淘汰」与调度抢占 GIL 的隐性 TTFT 瓶颈——和 vLLM 把调度核心往 Rust/C++ 沉降是同一股趋势。前缀复用负载在高并发下免费降时延，这是「白嫖」红利里最实在的一项。

## 二、vLLM & SGLang 社区跟踪

**版本状态**：窗口内 **SGLang v0.5.21（10-02，779 PRs / 227 贡献者）正式发布，是本期唯一大版本**；**vLLM 主线推进至 v0.31.0rc3（Model Runner V2 线），仍以 v0.30.0 为稳定锚点**。

### vLLM（v0.30.0 稳定锚 · v0.31.0rc 收尾）

**版本 / 安全落地**：

- **版本**：`v0.31.0rc3`（约 10-01，仅 Model Runner V2 支持 randomized dummy inputs `#58411`），rc1/rc2/rc3 均 CI/Bugfix，特性集待 **rc3+**；`v0.30.0`（09-22，762 commits / 315 贡献者）仍为 **PD 分离生产推荐升级目标**——承载 **CVE-2026-93436** 修复（PD 分离下被拒请求 decode 侧 metadata 未释放致内存耗尽，CVSS 8.7，修复 `#55677`）、Fast Start、HiSparse、双键水印、MRV2 图冻结。
- **补丁线**：`v0.30.1rc0`（09-23）含 **AMD MI355 dense NVFP4 + MoRI kernel 镜像（#58281）**，承载 AMD NVFP4。
- **前瞻 PR（已合 main 未进 release）**：**DSV3.2 DSA decode 持久化 TopK（#37421）、DSA+MTP IMA 修复（#40772）、3FS KVConnector（#37636）、P/D prefill offload 全部 KV blocks（#40346）、FlashInfer NVLink MNNVL workspace（#40893）、CPU draft 投机（#32662）**——DeepSeek-V3.2/DSA 生态快速成熟，与本人 OpenInfer/DFlash/DSpark 主线同构。
- **安全**：**CVE-2026-93436（CVSS 8.7）影响 ≤0.29.0 的 PD 分离内存耗尽**——生产须升 **0.29.1 / 0.30 / 0.30.1**。

### SGLang（v0.5.21 · Rust 前缀缓存 + PD 热切换 GA + 十款 day-0）

**新特性 / 架构演进**：

- **v0.5.21（10-02，779 PRs / 227 贡献者，Latest）**：窗口内唯一正式大版本，升级即白嫖默认能力——前缀缓存默认跑在 **Rust 核心（#39627）**、PD 实例 **prefill↔decode 即时切换无需重启（#28403 今 GA）**、**DeepSeek-V4.1 长提示首 token +22%（#40352）**、**Kimi K3 PD prefill 吞吐 +20.6%（#40045）**。
- **day-0 新模型（十款）**：DeepSeek-V4.1 Flash、GigaChat 3.5、IQuest-Q1、MiMo-V2.6/Pro、Ling-3.0-flash-VL、DiffusionGemma、Qwen-Image 2.1、Anima Base v1.0、Ming-Image 0.1、FLUX 3 Action。
- **AMD**：**GLM-5.3-Flash 现可在 AMD MI355X 跑 FP8/MXFP4 MoE + MTP 投机（#38546/#39341/#39778）**。
- **API 范式扩展**：新增 **Decisions API（/v1/decisions，#41208）** 与 **Score API（/v1/score，#38965/#41188）**。

### 原理：SGLang #39627 前缀缓存下沉 Rust 核心（高并发免费降时延）

- **做法**：把前缀缓存从 Python 层下沉到 **scheduler 的 Rust 核心**——缓存命中的**查询 / 插入 / 淘汰**与调度共用进程，原本在高 QPS 下因 **GIL 争用**成为隐性 TTFT 瓶颈；下沉后高并发前缀复用负载**免费降时延**。
- **同源趋势**：与 **vLLM 把调度核心往 Rust/C++ 沉降** 同方向——推理引擎的「热点路径去 Python」已成共识，Rust 核心 = 高并发下的时延确定性。

> 我的判断：前缀缓存看起来是「存 hit」的模块，实际上它的查询/淘汰在 Python 层会和调度抢 GIL，高 QPS 时反而拖 TTFT。SGLang 把它挪进 Rust 核心，等于把这块隐性瓶颈直接抹掉——这是 v0.5.21「白嫖」红利里最硬的一项，不是装饰。

### 论文核心（Gemini Robotics 2 · Google DeepMind，技术报告 2026-09）

- **一句话定位**：第二代通用机器人 **VLA 套件**——把具身 AI 从「单臂抓取」推向**整身（whole-body）控制 + 跨本体软件层平台化**。
- **核心做法**：**ER 2** 负责 VLM 推理规划、**Gemini Robotics 2** 负责整身动作、**On-Device 2** 负责端侧小样本迁移；**同一 checkpoint** 可驱动 Apollo 2 + 五指/二指手、Franka Duo + 夹爪；多机协作与 **ASIMOV-Agentic** 安全基准同步推出。
- **影响**：把具身 AI 推向**软件层平台化**——同一套「大脑」跨本体复用，利好大脑算法、端侧算力与核心零部件供应链，加速「本体 + 第三方大脑」解耦分工。

### 算子讲解：DyT（Dynamic Tanh, Transformers without Normalization, Zhu et al., CVPR 2025, arXiv:2503.10622）

- **定位**：用**可学习 tanh 曲线**替代 LayerNorm/RMSNorm——公式 **DyT(x)=γ·tanh(αx)+β**；**LLaMA 8B 训练省 42.2%、推理省 52.4%**，跨 ViT/MAE/DiT/LLaMA 验证，是端侧 VLA 归一化层降本候选。
- **意义**：归一化层不是「免费午餐」——DyT 证明它可以整层省掉，对端侧/整身 VLA 这种时延敏感场景是直接的层成本下降。

### 性能优化：AdaEAGLE（自适应投机解码, SJTU, arXiv:2412.18910）

- **定位**：在 **EAGLE** 上加轻量**草稿长度预测器 LDLP**，动态决定每步草拟 token 数，**1.62× 无损加速**；与 **JetSpec（算法层）、DSpark（系统层）、SpecDec++（阈值 MDP）** 正交，共同服务 VLA 端侧低时延控制。
- **同族**：和本人 OpenInfer/DFlash 候选选择器同属「投机解码精细化」大方向——草稿结构怎么定、怎么自适应，比固定 K 更贴近真实接受长度。
