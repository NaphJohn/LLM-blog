## ★ 今日最值得关注

**阶跃 Step 5 Preview 将于 10-15 开源权重、媒体称其 6 月底已秘密递表港交所冲刺年底挂牌，国产推理生态最大事件进入「开源 + 上市」双兑现窗口；SGLang #40826 把候选 token 打分校准前移到 verify 之前，与本人 OpenInfer/DFlash 候选选择器同源，直接减少投机解码的「验证后 reject」浪费。** 今天最该进你「升不升 / 要不要等」决策表的，是 Step 这条线同时站在两条兑现曲线上——开源权重 13 天后落地、资本端冲刺年底挂牌——而 SGLang 仍在 main 上把投机解码的结构件往前推。

三层事实：

1. **版本与事件**：阶跃 **Step 5 Preview** 将于 **10-15 开源权重**（距今 13 天），且媒体称其 **6 月底已秘密递表港交所**、冲刺年底挂牌——这是国产推理生态今年以来最大事件，进入「开源 + 上市」双兑现窗口；框架侧暂无适配 PR，Step-3.7-Flash 双框架成熟（vLLM `stepfun37`+MTP-3 ＞ SGLang `dev`+EAGLE，NVFP4 4 卡）。
2. **SGLang 投机解码推进**：**#40826（09-24）候选 token 打分与校准**——draft 生成块/树候选后、给每个候选单独打分并校准为可比较置信度，低置信候选在 verify 前剪枝，减少「验证后被 reject」浪费；与本人 OpenInfer/DFlash/DSpark（Qwen3-4B）候选选择器同源，建议复现 per-item 校准对照 accept length 收益。横向：vLLM online acceptance estimator（#52228）是「验证后」估计，SGLang 此 PR 前移「验证前」打分，二者互补。
3. **架构路线确认**：PyTorch Conf Europe 2026 确认 vLLM **Q 路线**——MRV2 默认化、vLLM IR、Omni RDMA 解聚合、弹性/容错 EP。

**可执行结论**：Step 5 权重 10-15 开源前，先按 Step-3.7-Flash 双框架成熟路径备好部署；想试 SGLang 新结构件从 main 构建、盯 **v0.5.21**；生产 PD 继续锚定 **v0.30.0**（仍承载 CVE-2026-93436 修复，生产须 ≥0.29.1）。

> 值得强调：#40826 把「候选打分」前移到 verify 之前，和本人 DFlash 候选选择器是同一个洞见——候选怎么排、怎么校准，比候选由谁生成更直接影响 E[L]（接受长度）。投机解码真金白银的吞吐账，就落在这一个旋钮上。

### vLLM（v0.30.0 稳定锚 · v0.31.0rc 收尾）

**版本 / 安全落地**：

- **版本**：`v0.31.0rc1/rc2`（rc1 09-30 CI/Build `#59118`、rc2 10-01 Mamba prompt-end prefill 检查点 bugfix），特性集待 **rc3+**；`v0.30.0`（09-22，762 commits / 315 贡献者）仍为 **PD 分离生产推荐升级目标**——承载 **CVE-2026-93436** 修复（PD 分离下被拒请求 decode 侧 metadata 未释放致内存耗尽，CVSS 8.7，修复 `#55677`）、Fast Start、HiSparse、双键水印、MRV2 图冻结。

### SGLang（v0.5.20 · --attn-dp-size + 候选打分 + FA4 ViT + gfx950）

**新特性 / 架构演进**：

- **#41818（09-30）**：新增 **`--attn-dp-size`** 并弃用 `--enable-dp-attention`——注意力数据并行成独立旋钮，利于 PD 分离长上下文 decode 吞吐。
- **#40826（09-24）**：**候选 token 打分与校准**，与 DFlash2 候选选择器同构，利好投机解码接受率（见原理）。
- **#41344（09-27）**：把 **FA4（FlashAttention-4）引入 ViT 视觉塔**（SM100/SM103），多模态图像编码吞吐提升。
- **#39273（10-01）**：AMD **gfx950 GLM-5.3-Flash** 支持 FP8 + MXFP4。

### 原理：SGLang #40826 候选 token 打分校准（投机解码减浪费）

- **做法**：draft 网络生成块 / 树候选后，**给每个候选单独打分并校准为可比较置信度**，低置信候选在 **verify 之前剪枝**，减少「验证后被 reject」浪费——验证本身有成本，把注定失败的候选挡在验证前就是纯赚。
- **同源**：与本人 OpenInfer/DFlash/DSpark（Qwen3-4B）候选选择器同源——都相信「候选怎么排、怎么校准」决定 E[L]；建议复现 per-item 校准对照 accept length 收益。
- **横向**：vLLM online acceptance estimator（#52228）是「验证后」估计，SGLang 此 PR 把打分**前移**到「验证前」，二者互补——一个事后纠偏、一个事前裁剪。

> 我的判断：投机解码的「候选选择器」不是装饰。#40826 前移打分证明——与其在验证阶段被动接受 reject，不如在验证前主动剪枝。这正是 DFlash 候选选择器一直在做的事，今天又见一次工程同构。

## 三、AI 论文与产业热点

### 今日重点（1 句）

**智源开源的 RoboBrain 2.0 把「感知-推理-规划」统一进一个具身大脑模型，空间 + 时序基准双料第一超 GPT-4o/Gemini，与今天「优必选进空客 / 智元 2 万台 / 宇树净利 +956%」的量产新闻拼出「大脑-小脑-本体」完整产业链；算子侧 MoBA 把 MoE 路由思想搬进注意力（1M 上下文 6.5×、10M 16×+），SpecDec++ 用阈值策略把自适应草稿长度形式化为 MDP（比固定 K +7.2~11.1%）；产业侧 DeepSeek V4.1 Flash 连续两周 OpenRouter 周榜第一（19.6 万亿 token/周 +24%）、Anthropic 递表 IPO（估值超 $2T）。**

### 论文核心（RoboBrain 2.0 · BAAI 智源, arXiv:2507.02029）

- **一句话定位**：具身视觉-语言基础模型「机器人大脑」——把**感知、推理、规划**统一进一个模型，输入高分辨率图/多视图/视频/场景图 → 统一 token 序列，输出任务文本、精确坐标（pointing/轨迹）、CoT 推理链。
- **核心做法**：**7B / 32B** 双版本、**Qwen2.5-VL 初始化**（689M 视觉编码器 + MLP 投影 + LLM 解码器）、全套开源；三阶段训练（基础时空学习 → 224K 具身时空增强 → CoT-SFT 195K + GRPO RFT 45K，复合奖励 = 正确 + 格式）。
- **结果**：空间 **9 项基准刷新**（BLINK 83.95 / CV-Bench 85.75 / Where2Place 73.59）、EgoPlan2 58.14、Multi-Robot-Plan 81.83，**超 GPT-4o / Gemini / Claude 闭源基线**。
- **影响**：具身「大脑-小脑-本体」分层成型——开源大脑降低整机厂自研门槛，加速「本体 + 第三方大脑」解耦分工。

### 算子讲解：MoBA（混合块注意力，月之暗面 Kimi, arXiv:2502.13189）

- **定位**：把 **MoE 路由思想搬进注意力**——上下文切块，query 用**无参 top-k 门控**只看最相关 k 个 KV 块（O(N²) → O(N·k·B)）；**1M 上下文 6.5×、10M 16×+**，RULER 与全注意力持平。
- **在用 / 相关**：已部署支撑 **Kimi 长上下文**；与 **DeepSeek NSA** 同月「撞车」（NSA 可学习三分支 vs MoBA 无参单机制），需 continued training 非即插即用。

### 性能优化：SpecDec++（自适应草稿长度，Princeton, arXiv:2405.19715, COLM 2025）

- **定位**：把「继续草拟 vs 提交验证」形式化为 **MDP**，证明最优策略 = **阈值策略**——草稿模型加 **acceptance prediction head**，预测拒绝概率超阈值即停；**llama-2-chat 7B&70B** 上 Alpaca **2.04×** / GSM8K **2.26×** / HumanEval **2.23×**（比固定 K **+7.2~11.1%**）。
- **同族**：与 **JetSpec（管法）、DSpark（管场）** 正交拼图，管「**时机**」——和 #40826 候选打分同属「投机解码精细化」这一大方向。
