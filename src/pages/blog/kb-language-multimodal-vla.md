## 1. 主线：从"语言生成"到"具身行动"

这一篇把几篇奠基性工作串成一条清晰的主线：

> 生成式预训练（会"写"语言） → 多模态指令微调（会"看+说"） → 视觉-语言-动作模型 VLA（会"动手"） → VLA + 世界模型（会"先想再动"）。

对投资视角的启示：具身智能的"大脑"并不是凭空出现的，而是沿用了语言/多模态大模型已经验证的预训练+微调范式，差别只在于输出空间从"文本 token"逐步扩展到"动作 token"。

## 2. GPT-1：生成式预训练+微调的种子范式（Radford et al., 2018）

- **一句话定位**：首次证明"生成式预训练 + 下游微调"可以横扫 NLU 任务，写好了后来 ChatGPT 的全部基因。
- **核心公式**：先在 BookCorpus 上做因果语言建模 `L₁ = Σ log P(uᵢ | u<i; Θ)`，再迁移 `Θ` 加线性头 `W_y` 微调，辅以 `λ·L₁` 防遗忘。
- **架构**：Decoder-only Transformer，12 层、d=768、h=12、ctx=512、117M 参数（虽小，但路线完整）。
- **影响**：确立 GPT 路线 → GPT-2/3/4/ChatGPT；与 BERT（双向掩码）分庭抗礼，最终生成能力胜出。

## 3. LLaVA：把指令微调引入多模态（NeurIPS 2023 Oral）

- **核心创新**：用 GPT-4 根据 COCO captions "想象"出 158K 条多模态指令数据（对话/描述/推理三类，零人工标注）。
- **极简架构**：冻结 CLIP ViT + 一个可训练线性投影 `W` + Vicuna LLM，两阶段训练（先对齐特征，再指令微调）。
- **效果**：GPT-4-as-Judge 相对分 85.1%，ScienceQA 92.53% SOTA。
- **范式意义**：确立了"冻结视觉编码器 + 投影桥接 + LLM 微调"的标准多模态 VLM 范式，催生 LLaVA-1.5/NeXT、CogVLM、InternVL、Qwen-VL 整条生态。

## 4. RT-2：首个大规模 VLA，让 VLM 直接输出机器人动作（Google DeepMind, 2023）

- **核心思想**：把 7-DoF 连续动作按 256-bin 离散化为**文本 token**，与语言共享输出空间；自回归生成动作字符串后解码执行（co-fine-tuning）。
- **效果**：unseen 任务成功率 RT-1 的 32% → RT-2 的 62%。
- **意义**：奠定了 OpenVLA / π0 / GR00T 等后续 VLA 路线——"机器人大脑"的本质是"把动作当语言来生成"。

## 5. π0.7 与 HiF-VLA：VLA 融合世界模型（WAM）

- **π0.7（Physical Intelligence）**：首次把**世界模型作为 Subgoal Image Provider** 集成进 VLA——行动前先在"脑中"预测子目标图像，再引导动作执行，克服纯 VLA 的"幻觉动作"。实测 ARX 机械臂学到的叠衣服能力**零适配迁移**到 UR5 双臂（跨本体泛化）。
- **HiF-VLA（西湖 MiLAB, CVPR 2026）**：Motion-centric 双向时空推理，联合专家同时预测"未来 Motion + 动作"。显存 31.4GB（基线 63.6）、延迟 117.7ms（基线 229.5），LIBERO-LONG SOTA。
- **终局共识（WRAM）**：VLA 与世界模型"融合共生"是具身智能的终局方向；数据仍是最大瓶颈（差 1~2 个数量级）。

## 6. 实践启示

- 评估具身公司/模型时，重点看三点：① 是否复用成熟 LLM/VLM 预训练范式（而非另起炉灶）；② VLA 是否引入世界模型做"先想再动"；③ 跨本体/零适配迁移能力（决定量产可复制性）。
- 这条主线也解释了为什么"大模型降本"直接利好具身：推理成本每降一档，端侧/机载实时 VLA 就多一分可行。
