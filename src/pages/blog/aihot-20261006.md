## ★ 今日最值得关注

**本期唯一重大版本事件——vLLM v0.31.0 稳定版于 10-05 正式发布（717 commits / 307 人），把 DFlash 块扩散投机解码带上 MRV2 异步执行路径、带来 Fast Restart 权重守护进程，终结了自 10-01 以来「候选版 limbo」的悬念；SGLang 仍坐 v0.5.21（10-01，779 PRs / 227 贡献者）但 main 在 PD 弹性与路由补齐上密集提交，Step 5 Preview 距 10-15 开源仅 9 天。其中最硬的一条：v0.31.0 把 DFlash 每步需重算的整段上下文 K/V 在 draft CUDA graph 捕获期固化一次（#57632），配合 MRV2 异步调度（#58065）让 draft 与 verify 重叠——对本人 OpenInfer/Qwen3-4B 可直接复用的「降每步 draft 开销、稳接受率、提端到端 decode 吞吐」模板。**

三层事实：

1. **版本与安全落地**：**vLLM v0.31.0（10-05，717 commits / 307 人）稳定版正式发布**——结束多周候选版飘摇；核心特性 **Fast Restart（`vllm preload` 权重守护进程跨重启免重载，含 DP/MTP 支持 #56680/#57386/#57312）**、**MRV2 + 投机解码成套（草稿模型投机解码 #43091、LiLiCorr drafter #57934、DFlash 异步 #58065 + 上下文 K/V 预计算入 draft graph #57632、DSpark 自适应验证 Gemma4 #57263）**。DSv4.1-Flash 内核融合（FlashMLA mega attention 成 SM100 默认 #56935、Mega-Gate #56266、Engram 跨 TP 分片 #58678）。稳定锚从 v0.30.0 上移到 **v0.31.0**。
2. **SGLang 与 Step 倒计时**：**SGLang 仍坐 v0.5.21（10-01，779 PRs / 227 贡献者，无 v0.5.22）**；main 在 **#40703（opt-in prefill-complete decode KV 分配）/ #41961（混合 SWA 池捕获后 KV 尺寸）** 推进 PD 弹性，sgl-router 补 **/v1/classify #42258、/v1/embeddings #42191、--worker-api-key 鉴权**，性能侧 **候选 token 打分校准 #40826、--attn-dp-size 一等化 #41818**。**Step 5 Preview 开源倒计时 9 天（10-15）**，社区 HF day-0 命令标准化；Step-3.7-Flash 双框架成熟仍为生产主力。
3. **论文信号**：**DINOv2（arXiv:2304.07193）「不贴标签训练通用视觉特征」**——LVD-142M + DINO 自蒸馏 + iBOT 掩码预测 + KoLeo 均匀性，1.1B ViT-g/14 拿 ImageNet linear 86.5% / ADE20K 63.0% mIoU，frozen features 直接当 VLA/机器人「眼睛」；配套 **Tree Attention（一次前向并行验证多分支投机，JetSpec Qwen3-8B MATH-500 9.6×）** 与 **GammaTune（训练-free 自适应草稿窗，SpecBench +15~16%）** 两张投机解码底牌。

**可执行结论**：生产从 v0.30.0 升级到 **v0.31.0** 直接拿到 DFlash 异步 + Fast Restart，并用 #57632 的「graph 内固化上下文 K/V」模板降 draft 开销；SGLang 生产继续锁 **v0.5.21**；Step 5 权重 10-15 落地后用 `--reasoning-parser stepfun` 双框架直接跑。

> 值得强调：v0.31.0 把 DFlash 每步重算的整段上下文 K/V 在 draft graph 捕获期只算一次（#57632），后续只算新候选注意力——这正是把「每步重算」的簿记从 eager 路径搬进 graph 捕获、再靠 MRV2 异步让 draft/verify 重叠。对本人 OpenInfer/Qwen3-4B DFlash 是现成可复用：降每步 draft 开销、稳住接受率、提端到端 decode 吞吐。代价是正确性更依赖 graph 内状态固化是否完整——上轮 #56158 的「FULL 图回放绕过 Python 守卫」仍是要盯的雷。

### SGLang（v0.5.21 · 版本号坐实 + main 近窗增量）

**新特性（已发版确认）**：

- **v0.5.21（10-01，779 PRs / 227 贡献者，Latest）**：前缀缓存默认 Rust 核心（#39627）、PD 角色热切换 GA（#28403）、DSv4.1 长提示 TTFT +22%（#40352）、Kimi K3 PD prefill +20.6%（#40045）、GLM-5.3-Flash 上 AMD MI355X、新增 Decisions/Score API。
- **main 近窗**：**#40703 opt-in prefill-complete decode KV 分配**、**#41961 混合 SWA 池捕获后 KV 尺寸** 推进 PD 弹性；sgl-router 补 **/v1/classify #42258、/v1/embeddings #42191、--worker-api-key 鉴权**；性能侧 **qwen 3.8 next 融合 NEXTN verify+draft graph 输入、候选 token 打分校准 #40826、--attn-dp-size 一等化 #41818**。

### 原理：vLLM v0.31.0 #57632——DFlash 上下文 K/V 在 draft graph 固化一次（graph 捕获期去重算）

- **做法**：DFlash 每步需重算的整段上下文 K/V，在 **draft CUDA graph 捕获期只算一次并固化**，后续每步只算**新候选 token 的注意力**；配合 **MRV2 异步调度（#58065）**让 draft 与 verify 在流水上**重叠**。
- **收益**：对本人 **OpenInfer/Qwen3-4B DFlash** 可直接复用——降每步 draft 开销、稳接受率、提端到端 decode 吞吐；代价是正确性依赖 graph 内状态固化是否完整（回看 #56158 FULL 图回放绕过 Python 守卫的雷）。

> 我的判断：v0.31.0 把「DFlash 异步 + graph 固化上下文 K/V + MRV2 异步调度」打包成稳定默认路径，是把投机解码簿记从 eager 路径迁到 GPU-Native/graph 的又一次踏实落地；与本人 OpenInfer/DFlash/DSpark 同源——核心都是「降每步 draft 开销、让 draft/verify 重叠」。迁移途中旧路径（FULL 图）仍会在长上下文高并发下咬人，所以上轮 #56158 的修复优先级依旧高。

## 三、AI 论文与产业热点

### 今日重点（1 句）

**DINOv2 用自监督把「通用视觉特征」训练到冻结即用的 VLA/机器人眼睛，配套 Tree Attention 树形投机验证（一次前向并行多分支，JetSpec Qwen3-8B MATH-500 9.6×）与 GammaTune 训练-free 动态草稿窗（SpecBench +15~16%）两张投机解码底牌，具身产业「量产-并购-融资」三连发（特斯拉 Optimus 产线改造周产数百台/年底破千/2026 目标 5 万、FieldAI 拟百亿估值融资、AMD 82 亿美元收购 World Labs 李飞飞入职、优必选自贡中标 1.59 亿元全年订单破 8 亿）。**

### 论文核心（DINOv2 · arXiv:2304.07193）

- **一句话定位**：**不贴标签训练通用视觉特征**——LVD-142M 精选数据 + 师生 EMA 自蒸馏（DINO）+ 掩码 Patch 预测（iBOT）+ 特征均匀性约束（KoLeo）。
- **规模与成绩**：训练 **1.1B ViT-g/14**，**ImageNet linear 86.5%、ADE20K +ms 63.0% mIoU**，冻结特征直接迁移。
- **影响**：frozen features 直接当 **VLA/机器人「眼睛」**，与 CLIP/SigLIP 语义对齐**互补**——语义 + 几何/结构两手都抓。

### 算子讲解：Tree Attention

- **定位**：**树形因果掩码注意力**——投机解码验证阶段**一次前向并行验证多分支**；已在 EAGLE / SpecInfer / JetSpec / vLLM / SGLang 落地。
- **收益**：**JetSpec Qwen3-8B MATH-500 9.6×**；VLA 可一次验证**多个动作 token**，与 Tree-of-thought 类规划天然契合。

### 性能优化：GammaTune

- **定位**：**训练-free 自适应投机解码草稿长度 γ**，EWMA 接受率驱动**动态扩缩窗**；代表工作 arXiv:2504.00030。
- **收益**：**SpecBench +15~16% 加速、方差更小**——把「固定 K 草稿」换成「随接受率自适应」，是 DFlash/Medusa 类方法的轻量加成。

### 产业热点（具身公司 / 产业链速递 · 置顶）

- **【具身】特斯拉 Optimus**：产线改造 **周产数百台、年底破千、2026 目标 5 万台** → 拓普/三花/绿的/均胜/机器人 ETF；**【具身】FieldAI**：拟融资 **7 亿美元、估值 100 亿美元**（通用机器人大脑）；**【具身】AMD 收购 World Labs**：**82 亿美元**收购、李飞飞入职 → 世界模型产业化加速；**【具身】优必选 09880.HK**：自贡中标 **1.59 亿元**、Walker 全年订单**破 8 亿元**。
