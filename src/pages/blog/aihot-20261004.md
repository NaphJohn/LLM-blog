## ★ 今日最值得关注

**周日非交易窗口里近 24h 无新正式版本，最大的窗口级更新（SGLang v0.5.21 / vLLM v0.31.0rc3）已在上轮（10-03）详列；本期主轴是版本号坐实 + main 分支近窗增量 + MRV2 原理深读。其中最硬的一条：vLLM 0.31 线拟把 MRV2 设为所有 dense 模型默认执行路径（并移除 PagedAttention）——继 SGLang 之后，第二个把调度核心全面下沉到 Rust/C++ 的主流推理引擎。**

三层事实：

1. **版本与事件**：**vLLM 0.31 开发线收敛**——RC 分支显示 **MRV2 拟设为所有 dense 模型默认执行路径（#44443）并移除 PagedAttention（#47361）**，Transformers 后端追平原生（#47187），新增 DSpark/DFlash drafters，GLM-5/DeepSeek-V3.2 进 model zoo；**SGLang v0.5.21（10-02，779 PRs / 227 贡献者，Latest）版本号坐实**，仍是窗口内唯一正式大版本。
2. **Step 倒计时**：**Step 5 Preview（09-20）开源倒计时 11 天（10-15 正式开源）**；BF16 权重已现 HF 社区仓（TypeSafeAI/SHSLab/ashuaria，归属官方未确认）；600B/27B 激活、1M 上下文、AA 开源前三、成本 1/8 Opus 5；双框架 day-0 命令标准化 `--trust-remote-code --reasoning-parser stepfun`（vLLM tp8 / SGLang tp8），距可跑仅剩权重开放。
3. **论文信号**：松延动力 **HERON** 把「动作条件世界模型预演未来」+「上下文强化动作模型从错误学习」合进 VLA 闭环，让机器人先想象再行动、跨本体迁移；算子 **Partial RoPE** 仅对注意力头前 25% 维度施加位置编码（Qwen3-Next/3.5 Gated Attention 在用），**HeteroSpec** 按 token 验证难度动态分配草稿/验证资源（4 模型 5 基准平均 4.26× 无损）。

**可执行结论**：想提前看懂 vLLM 0.31 的架构方向，盯 **MRV2 默认化 + PagedAttention 移除**（dense 模型零 API 变更即获更干净代码 + 更好性能）；SGLang 生产继续锁 **v0.5.21**；Step 5 权重 10-15 落地后用 `--reasoning-parser stepfun` 双框架直接跑。

> 值得强调：MRV2（Model Runner V2）= ModelState 抽象（私有模型不改共享路径）+ GPU-Native 输入准备（自定义 Triton kernel 替掉大量小 PyTorch CPU op 做批处理/分页注意力记账），原则是 **Modular / GPU-native / Async-First**。这和 SGLang 把调度往 Rust 沉降、和本人 OpenInfer/DFlash/DSpark 同属「调度/缓存热点路径去 Python」一股趋势——0.31 把 MRV2 设默认并移除 PagedAttention 后，dense 模型等于白拿一次底层重构。

## 二、vLLM & SGLang 社区跟踪

**版本状态**：窗口内 **SGLang v0.5.21（10-02，779 PRs / 227 贡献者）版本号坐实，仍是最新唯一大版本**；**vLLM 主线推进到 v0.31.0rc3（MRV2 线），仍以 v0.30.0 为稳定锚点**。

### vLLM（v0.30.0 稳定锚 · v0.31.0rc 收敛）

**版本 / 安全落地**：

- **版本**：`v0.31.0rc3`（10-01，#58411 MRV2 randomized dummy inputs）；RC 分支显 **MRV2 拟设所有 dense 模型默认执行路径（#44443）并移除 PagedAttention（#47361）**；`v0.30.0`（09-22）仍为 **PD 分离生产推荐升级目标**——承载 **CVE-2026-93436** 修复（CVSS 8.7，修复 #55677）、Fast Start、HiSparse、双键水印、MRV2 图冻结。
- **补丁线**：`v0.30.1rc0`（09-23）含 **AMD MI355 dense NVFP4 + MoRI kernel 镜像（#58281）**。
- **0.31 架构信号（已合 main，待稳定版确认）**：**Transformers 后端追平原生（#47187）、新增 DSpark/DFlash drafters、GLM-5/DeepSeek-V3.2 进 model zoo**——dense 默认路径切换在即。
- **安全**：**CVE-2026-93436（CVSS 8.7）影响 ≤0.29.0 的 PD 分离内存耗尽**——生产须升 **0.29.1 / 0.30 / 0.30.1**。

### SGLang（v0.5.21 · 版本号坐实 + main 近窗增量）

**新特性（已发版确认）**：

- **v0.5.21（10-02，779 PRs / 227 贡献者，Latest）**：前缀缓存默认 Rust 核心（#39627）、PD 角色热切换 GA（#28403）、DSv4.1 长提示 TTFT +22%（#40352）、Kimi K3 PD prefill +20.6%（#40045）、GLM-5.3-Flash 上 AMD MI355X、新增 Decisions/Score API。
- **main 近窗（10-01）**：**#39273 AMD DSpark draft metadata 进 CUDA graph**、#41986 GLM-5.3-Flash NVFP4 cookbook、#41766 Rust gRPC adapter、#41726 共享 runtime.v1 protobuf、**#41818 新增 --attn-dp-size 弃用 --enable-dp-attention**、#39012 bump transformers 5.17.0。

### 原理：vLLM MRV2（Model Runner V2）下沉调度核心（dense 零 API 变更白拿重构）

- **做法**：**ModelState 抽象**（封装模型特有逻辑，私有模型不改共享路径）+ **GPU-Native 输入准备**（自定义 Triton kernel 替掉大量小 PyTorch CPU op 做批处理/分页注意力记账）；原则 **Modular / GPU-native / Async-First**。
- **同源趋势**：与 **SGLang 调度往 Rust 沉降** 同方向——推理引擎「热点路径去 Python」已成共识；0.31 把 MRV2 设默认 + 移除 PagedAttention 后，dense 模型**零 API 变更**即获更干净代码 + 更好性能，和本人 OpenInfer/DFlash/DSpark 同源。

> 我的判断：MRV2 不是又一个重构名词，它把「分页注意力记账这种原本一堆小 PyTorch CPU op」换成自定义 Triton kernel 在 GPU 上准备输入，等于把调度热路径从 Python 里拔出来。配合移除 PagedAttention，dense 模型这一波是底层换骨、上层无感——和 SGLang #39627 前缀缓存下沉 Rust 核心是同一逻辑的两面。

### 常驻专题

**PD 分离**：SGLang **#28403 角色热切换 GA** + **Kimi K3 PD +20.6%（#40045）** + 前缀缓存 Rust 核心；vLLM 0.30 CVE 修复 + HiSparse + NIXL bugfix；外部综述确认 2026 PD 成行业默认，SGLang/Dynamo 文档化最完整，vLLM 仍 experimental（9 connector）。

**PyTorch vs transformers**：无脱离 PR；SGLang bump transformers 5.17.0、vLLM --model-impl transformers；边界重分层（模型定义收敛 transformers、性能层留引擎 kernel）结论维持。

## 三、AI 论文与产业热点

### 今日重点（1 句）

**松延动力 HERON 把「动作条件世界模型预演未来」与「上下文强化动作模型从错误学习」结合，让机器人先想象再行动、跨本体迁移；算子 Partial RoPE 仅对注意力头前 25% 维度施加位置编码（Qwen3-Next/3.5 Gated Attention 在用）改善长序列外推，HeteroSpec 按 token 验证难度动态分配草稿/验证资源（4 模型 5 基准平均 4.26× 无损）——与智元启元 19999 元发货、特斯拉 Optimus Gen3 泄露周产千台、优必选进空客、宇树净利 +955.6% 拼出具身「预演-执行-修正」闭环落地。**

### 论文核心（HERON · 松延动力 Scalabot，2026-09）

- **一句话定位**：具身智能「双脑」架构 = **HERON-World Model + HERON-CRA**——把 VLA 从「当前帧反应」升级到「预演—执行—修正」闭环。
- **核心做法**：**统一动作表示**对齐真实/仿真/人类视频；**World Model 生成未来视频**做预演；**CRA** 通过 **Context Expert** 形成 4D 记忆、**RL Engine** 用 Value Model 残差 RL 纠错、**Cross-Embodiment Pretraining** 跨本体迁移。
- **影响**：预演—执行—修正闭环利好长程家庭/商业服务场景，跨本体迁移降低单本体数据成本。

### 算子讲解：Partial RoPE（部分旋转位置编码）

- **定位**：仅对注意力头**前 25% 维度**施加 RoPE，其余维度无位置，改善长序列外推；**head_dim=256 时 d_rope=64**；与 **Zero-Centered RMSNorm、GQA** 配套。
- **意义**：全量 RoPE 在超长上下文会过旋转、外推不稳；只对头部少量维度加位置，既保留局部位置敏感又稳住长程——VLA 长视频历史更稳，是长上下文（Qwen3-Next/3.5 Gated Attention）的标配技巧。

### 性能优化：HeteroSpec（异构感知投机解码, arXiv:2505.13254，PKU / SCITIX）

- **定位**：按 **token 验证难度动态分配草稿/验证资源**，简单 token 少草多验、难 token 多草少验；**4 模型 5 基准平均 4.26× 加速，无损、无需重训练**。
- **同族**：与 **JetSpec（算法层）、DSpark（系统层）、SpecDec++（阈值 MDP）** 正交，共同服务 VLA 端侧低时延控制——和本人 OpenInfer/DFlash 候选选择器同属「投机解码精细化」大方向。
