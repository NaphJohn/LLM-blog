## ★ 今日最值得关注

**SGLang 全版本 RCE（CVE-2026-111391, CVSS 9.2）：修复在 main，但没有任何 release 带上它。**

这是本期唯一一条"会直接让攻击者拿到你集群执行权限"的问题，而且它的麻烦和 9 月那次一样——不在漏洞本身，而在**修复的可达性**。

三层事实：

1. **症状/范围**：SGLang 的 **Dumper `eval()` RCE**，CVSS **9.2**，**影响 0.5.10–0.5.22 每一个可装版本**。也就是说，你现在能 pip 装到的 SGLang，无一幸免。
2. **修复**：PR **#44205**（AST 白名单求值器）已合 **main**。
3. **问题**：**未进任何 release**，最新 **v0.5.22 仍受影响**。

**可达性判断**：默认 `DUMPER_SERVER_PORT` 未设置 → 不是公网 mass-exploit 级蠕虫，但在**长期挂着调试端口的集群**（多人共享调试环境、忘了关的 dev 部署）里风险极高。

**可执行缓解（在没有 release 修复之前，这是你唯一能做的）**：

- `unset DUMPER_SERVER_PORT`（关掉危险面）
- 在网络层**封掉 `/dumper/configure`**
- 设置**独立的 `admin_api_key`**

> 值得单独说的一点：又是一次"**修复在 main，但发布通道没跟上**"。和 9 月 SGLang NVFP4 那次如出一辙——它再次证明你的依赖管理里必须有一条**从 main 构建的应急路径**，以及一个**安全公告订阅机制**：否则一个 CVSS 9.2 会在你毫无察觉的情况下，停留在你生产环境的每一个节点上。

### 原理：vLLM Push-Based NIXL KV 传输

本期最值得理解的一条工程解读——它把"PD 分离怎么快"从黑话讲成了可落地的开关。

**默认 pull 模式的瓶颈**：首 token 关键路径上串行执行「router 转发 metadata → decode 分配目标块 → NIXL READ 拉取」，三次往返都卡在延迟敏感的临界路径上。

**push 模式做的事**：让 **decode 实例提前注册目标块**——prefill 还在算 KV 的时候，目标块就已经登记好了。于是传输协调与 setup 被挪到 **prefill 侧 + 后台线程**，关键路径上不再有 round-trip 和 decode 侧 setup 阻塞。

**收益**：1P1D（Qwen3-32B, P5en EFA）**TTFT 最高 3×、TPOT +30%**；**加速器无关**（Trainium 验证后贡献给 vLLM，GPU 同样受益）。

> 我的判断：做 PD 分离 + NIXL 的团队，**现在就可以直接启用 push connector**，这是一次"改个配置就吃到的 3×"，不值得等到下个版本。它再次印证一个趋势——推理引擎的竞争焦点，正从"单卡吞吐"转向"跨实例调度延迟"。

## 三、AI 论文与产业热点

> 今日论文＋产业摘要到齐，以下为核心提炼（对齐谱系第三讲 / 算子 / 性能优化 / 产业）。

### 论文核心：DPO（Direct Preference Optimization, arXiv:2305.18290, NeurIPS 2023）

**一句话定位**：免奖励模型、免 RL，直接从成对偏好数据学对齐——**LM 本身就是隐式奖励模型**。

**核心思想**：KL 约束奖励最大化有**闭式最优解** → 反解 `r = β·log(π/π_ref) + β·log Z` → 代入 Bradley-Terry 后，配分函数在胜负作差中**消去** → 损失坍缩为 **`L = −log σ(βΔ_w − βΔ_l)`**，一个**二元分类损失**。

**影响**：Zephyr / Llama 3 / Tülu 3 标配；TL;DR 胜率 **61% vs PPO 57%**、开销约 **1/3**；变体 IPO/KTO/SimPO/GRPO 谱系庞大；坑 = **likelihood displacement** 与**离线无探索**。

> 这条在今天格外应景：当推理引擎（见上）把复杂度推到操作系统量级，对齐侧却用 DPO 把 RLHF 的"两阶段工程"压成了一个分类损失——**两边的工程哲学恰好相反：一个在加层，一个在减层。**

### 算子讲解：Weight Tying（Press & Wolf, EACL 2017）

输入词嵌入与输出投影**共享同一份 V×d 矩阵**，省下一整份参数（Llama-3-8B 约 **13%**）；GPT-2/Gemma/Qwen3 小杯绑定、Llama 7B+ 解绑。在用模型：Gemma、Qwen3 0.6B–4B、SmolVLA 骨干 SmolLM2。关键点：RT-2/WorldVLA 把动作 token 共享语言嵌入空间，是其多模态延伸；坑 = **绑定权重勿重复量化**。

### 性能优化：Fiddler（UT Austin, arXiv:2402.07033, ASPLOS）

**模型 > 显存的 MoE 单卡推理**——**搬激活不搬权重**（传输量差三个数量级）+ **shadow execution 并行赛跑**藏访存；**24GB GPU 跑未量化 Mixtral-8x7B（>90GB）>3 tok/s，最高 22.5×**。具身关联：机器人板载小 GPU + 强 CPU 的**第三条端侧降本路线**。
