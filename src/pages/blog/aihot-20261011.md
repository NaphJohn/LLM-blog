## ★ 今日最值得关注

**本期最大事件为国产侧阶跃 Step 5 Preview 登顶 OpenRouter Trending 全球第一、日榜第二（10-10），正式开源定档 10-15（倒计时 4 天），社区 HF 镜像 TypeSafeAI/SHSLab Step-5-Preview-BF16 已给出 vLLM/SGLang 双框架 day-0 命令（--trust-remote-code --reasoning-parser stepfun），无需官方合并即 day-0 跑通。其中最硬的一条：Step 5 激活仅 27B（4.5%）决定每 token FLOPs 与 KV 增速、EP 按 27B 规划，Block-wise Token Merging 把 Indexer+Top-k 成本降 8×，使超稀疏在解码端划算——与本人 OpenInfer/Qwen3-4B DFlash「用更少激活参数换更低单步成本」的结构性思路同构，但正确性依赖自定义代码加载是否干净。**

三层事实：

1. **版本与安全（小版本 RC + 稳定锚不变）**：**vLLM 切 v0.31.1rc0（10-07）新增「按缓存层级暴露已命中 prompt token」指标 #56318**，利好分层 KV 缓存运维观测；**稳定版仍 v0.31.0（10-05，717 commits / 307 人）**，含 MRV2+DFlash 异步+Fast Restart+HiSparse 加固并承载 CVE-2026-93436 修复。**SGLang 稳定版仍 v0.5.21（10-02，779 PRs / 227 贡献者），窗口内未发 v0.5.22**。影响：生产稳定锚不变（vLLM v0.31.0 / SGLang v0.5.21），本期是「小版本 RC + 主线增量」而非「大版本刷新」的故事。
2. **架构演进（四模态统一 + FA4 默认）**：**vLLM Transformers 后端补齐视频输入 #57441（10-05 合并，随 v0.32.0 进稳定）**，文本/图像/音频/视频四模态统一，依赖 Transformers≥5.18.0；**SGLang main 近窗 #41886 在 SM100 把 FA4 设为 MiMo 默认注意力后端（decode 1.85×）**，Weight Cache Daemon 一期 Qwen3-235B FP8 冷启 300s→<1s，HiSparse 长上下文标注生产可用。
3. **论文信号**：**LaST-VLA（清华×小米EV，arXiv:2603.01928）把推理从文本 CoT 搬进连续隐空间、用 VGGT/Cosmos 特征级 MSE 蒸馏上物理镣铐（推理期适配器丢弃零开销）**，NAVSIM 双榜 SOTA 且 2B 打平 8B；配套 **VGGT 交替注意力（CVPR 2025 Best Paper，一次前向 0.51s 出 32 视图 3D 属性、替代 SfM/BA）** 与 **Shallow-π（三星，π 类 VLA 主干+动作头同步 18→6 层蒸馏、364ms→110ms、3Hz→10Hz）** 两张落地底牌。

**可执行结论**：生产继续锁 **v0.31.0（vLLM）/ v0.5.21（SGLang）**，本期先把 #56318 分层 KV 指标接进监控、#57441 四模态统一等 v0.32.0；Step 5 权重 10-15 落地后用 **8×H100 BF16 / 4×H100 FP8 + --reasoning-parser stepfun** 双框架直接跑；LaST-VLA 的「隐空间物理推理」范式可迁移到本人车端/具身 VLA 路线，先把 2B 打平 8B 的账算清。

> 值得强调：Step 5「激活 27B（4.5%）决定账单」与本人 OpenInfer/DFlash「用更少激活参数换更低单步成本」同构——Block-wise Token Merging 把 Indexer+Top-k 成本降 8×，正是超稀疏在解码端划算的关键。代价是 day-0 命令靠 --trust-remote-code 加载自定义模型代码，正确性依赖这份代码是否干净（权重来自社区镜像、归属未完全确认、无独立 benchmark），先用非生产环境验证再上量。

## 二、vLLM & SGLang 社区跟踪

**版本状态**：本期 **vLLM 切 v0.31.1rc0（小版本 RC）+ 稳定版 v0.31.0 保持，SGLang 稳定版 v0.5.21 保持（无 v0.5.22）**——主线在「分层 KV 可观测 + 四模态统一 + FA4 默认」方向增量收口，而非大版本号刷新。

### vLLM（v0.31.0 稳定版保持 + v0.31.1rc0 指标增量）

**版本 / 安全落地**：

- **版本**：**稳定版仍 v0.31.0（10-05，717 commits / 307 人）**，窗口内无新稳定 tag；主线 10-07 切 v0.31.1rc0 仅新增可观测指标，属补丁 RC。影响：生产仍以 **v0.31.0** 为目标，升级先回归 MRV2+DFlash 组合。
- **重要 PR（可观测）**：**v0.31.1rc0 新增「按缓存层级暴露已命中 prompt token」指标 #56318**——把分层 KV 缓存的命中情况按 tier 暴露，利好分层 KV 缓存运维观测。
- **架构演进（多模态）**：**Transformers 后端补齐视频输入 #57441（10-05 合并，随 v0.32.0 进稳定）**，文本/图像/音频/视频四模态统一，依赖 Transformers≥5.18.0。
- **稳定基准**：v0.31.0 含 MRV2+DFlash 异步+Fast Restart+HiSparse 加固，承载 CVE-2026-93436 修复。

### SGLang（v0.5.21 · 版本号坐实 + main FA4 默认）

**新特性（已发版确认 + main 近窗）**：

- **v0.5.21（10-02，779 PRs / 227 贡献者，Latest）**：前缀缓存默认 Rust 核心（#39627）、PD 角色热切换 GA（#28403）、DSv4.1 长提示 TTFT +22%（#40352）、Kimi K3 PD prefill +20.6%（#40045）、新增 Decisions/Score API。
- **main 近窗**：**#41886 在 SM100 把 FA4 设为 MiMo 默认注意力后端（decode 1.85×）**；Weight Cache Daemon 一期 Qwen3-235B FP8 冷启 300s→<1s；HiSparse 长上下文标注生产可用。
- **社区讨论**：stepfun `--reasoning-parser stepfun` 双框架 day-0 成熟（vLLM stepfun37+MTP-3 > SGLang dev+EAGLE，NVFP4 4 卡），社区镜像 TypeSafeAI/SHSLab 给出标准化部署命令。

### 原理：Step 5 Preview——激活 27B 决定账单，Block-wise Token Merging 降 8×

- **做法**：Step 5 总参 600B / 激活 27B 超稀疏 MoE、92 层窄深、Sparse GQA、Block-wise Token Merging 降 Indexer 成本 8×、1M 上下文、原生文本+视觉；激活 27B（4.5%）决定每 token FLOPs 与 KV 增速、EP 按 27B 规划——超稀疏在解码端划算的关键在 Block-wise Token Merging 把 Indexer+Top-k 成本压 8×。
- **收益**：AA 指数 44（开源前三），单任务成本约 Opus 5 的 1/8、输出 99.8 tok/s；day-0 命令靠 --trust-remote-code 加载自定义模型代码 + --reasoning-parser stepfun 注入推理协议，双框架无需官方合并即 day-0 跑通。建议提前备好 **8×H100(BF16) / 4×H100(FP8)** 与推理解析器配置。

> 我的判断：本期版本号稳（v0.31.0 / v0.5.21），增量集中在「分层 KV 可观测（#56318）+ 四模态统一（#57441）+ FA4 默认（#41886）」三条线——都是把运维/多模态/注意力后端做实，而非堆新功能。Step 5 登顶 OpenRouter 把「激活参数决定账单」这一结构性论点再次摆上台面，与本人 OpenInfer/DFlash 同构；但社区镜像权重归属未完全确认、无独立 benchmark，先非生产验证再上量。

### 常驻专题

**PD 分离**：vLLM v0.31.1rc0 缓存 tier 指标 #56318 补强可观测性；SGLang 维持 #28403 角色热切换 GA + kv-hints #38891 + #40703/#41961——走向可验证、可弹性、可自愈。

**架构演进**：vLLM 四模态统一 #57441(v0.32.0)；SGLang FA4 MiMo 默认 1.85× #41886；投机块级验证仍两家主线；KV 数值继续下探 NVFP4/FP4。

**PyTorch vs transformers**：vLLM #57441 让 transformers 后端覆盖视频，边界重分层延续（模型定义收敛 transformers、性能层留引擎 kernel），无脱离 PR。结论：模型层收敛 transformers、性能层留引擎 kernel，维持。

**Step 适配**：Step 5 社区镜像 day-0 双框架命令标准化、10-15 官方开源；Step-3.7-Flash 双框架成熟（vLLM stepfun37+MTP-3 > SGLang dev+EAGLE，NVFP4 4 卡）。

### 论文核心（LaST-VLA · arXiv:2603.01928）

- **一句话定位**：**把推理从文本 CoT 搬进连续隐空间**——双流隐式 CoT（H_geo 几何 / H_dyn 动态），用 VGGT/Cosmos 特征级 MSE 蒸馏上物理镣铐（推理期适配器丢弃零开销），NAVSIM 双榜 SOTA 且 2B 打平 8B。
- **做法**：① 双流隐式 CoT（H_geo 几何 / H_dyn 动态）在隐空间做「有物理约束的思考」；② VGGT/Cosmos 特征级 MSE 蒸馏，推理期适配器丢弃、零额外开销；③ 渐进 SFT（视觉瓶颈掩码强制先想后答）+ GRPO 轨迹奖励。
- **影响**：隐式推理从此有「教师在场」范式——物理约束在前向里就压住，车端部署成本下移，2B 打平 8B 意味着小模型也能吃下「物理思考」。

### 算子讲解：VGGT 交替注意力（CVPR 2025 Best Paper）

- **定位**：帧内↔全局注意力交替 24 层 + camera token，一次前向 0.51s 出 32 视图全套 3D 属性（深度/位姿/点云），替代 SfM/BA 后处理。
- **关键点**：首帧独立可学习 token 锚定世界坐标系；200 帧显存 ≈40GB；在用：VGGT 本体、LaST-VLA 几何教师、DriveVGGT——是「端到端 3D 先验」派的代表。

### 性能优化：Shallow-π（三星，IROS 2026 最佳论文候选）

- **定位**：π 类 VLA 主干+动作头同步 18→6 层蒸馏，把深主干压到浅主干。
- **收益**：364ms→110ms、3Hz→10Hz、成功率 -<1pp；插销入孔学生 10/10 > 教师 7/10（快能追上动态目标）——「浅而快」在闭环任务上先赢一局。
