## ★ 今日最值得关注

**SGLang 的 CVE-2026-111391：CVSS 9.2 的 dumper eval() 注入，尚无补丁，且 v0.5.23 也没修。**

这是本期唯一一条"会直接把你线上服务变成远程执行入口"的问题——而且它的麻烦不在漏洞本身，而在**修复的可达性**。

三层事实：

1. **症状**：SGLang `dumper/configure` 的 `eval()` 注入（CVE-2026-111391，CVSS **9.2**），攻击者一旦能触达 dumper 服务即可远程代码执行。不是轻微越权，是直接 RCE。
2. **修复**：修复 PR **#44205 已被关闭、未合并**；最新稳定版 **v0.5.23 同样未修**。
3. **影响面**：**0.5.10–0.5.22 全部中招**，加上未修的 v0.5.23，基本覆盖了今天绝大多数线上部署。

**可执行结论**：在官方补丁发布前，唯一防线是部署侧三件套——**保持 `DUMPER_SERVER_PORT` 不设置 + 设置 `admin_api_key` + 端口仅限回环 / 私有网络**。这条 CVE 与峰会"先稳住再上量"的节奏一致：本周主线是硬化，不是上新。

> 值得单独说的一点：修复 PR 被关、跨多个稳定版都拿不到补丁，比漏洞本身更值得警惕。它意味着你的依赖管理里必须有一条**从 main 构建的应急路径**——不是因为你想追新，而是因为你需要一个在"漏洞披露"和"下一个 tag"之间的逃生舱。

### 原理：Kimi K3.1 Pro 的 DSA 稀疏注意力

本期最值得理解的一条技术解读。

每层 **MLA 旁挂一个轻量 Indexer**——**FP8 key + 32 头打分，只保留 top-2048**。工程上把 **MLA latent + Indexer keys + KDA 状态打包进同一分页缓存**（PD 分离可整块传输）；**token-sharded prefill** 让 340K token / 8×GB300 的 TTFT 比 head-sharded **快 1.69×**；**DCP8 容纳的 KV 是 TP8 的 7.2×**。

> 该机制与 **Step 5 Preview 的稀疏注意力（Indexer + Region）同源**。提前看懂 K3.1 Pro，基本就等于看懂 Step 5 的长上下文部署形态——这是本周最划算的一笔"预习投资"。

### 常驻专题

**纯 PyTorch vs transformers**：近 72h 无新重大自研栈 PR；**Shrike**（纯 PyTorch 零依赖 PagedAttention + 投机 + OpenAI API）与 **NanoInfer**（纯 CUDA GPT-2 INT8 A100 1180 tok/s）仍为参照。结论 = 生产框架 + transformers 桥 vs 研究纯 PyTorch。

## 三、AI 论文与产业热点

### 论文核心

**Hi Robot**（Physical Intelligence, arXiv:2502.19417, CoRL 2025）【具身智能】

- **一句话定位**：分层交互式 VLA——高层 **PaliGemma-3B VLM ~1Hz** 输出低层语言命令，低层 **π0 50Hz** 执行动作块。
- **核心思想**：System2 / System1 分层学"说什么"与"怎么做"；约 1000 条遥操作切 1–3s 技能段，教师 VLM **hindsight 反推**用户提示 / 插话作合成监督（去合成数据 **IA −46%**）。
- **影响**：π0.5 / Helix / DriveVLM 同范式；hindsight 反推监督 = 人机交互数据稀缺的通用解法；vs GPT-4o 高层 **IA +40%**，vs flat VLA **IA +34% / TP +19%**。

**FlexiViT**（Google, arXiv:2212.08013, CVPR 2023）

- **定位**：patch size = ViT 精度 / 算力旋钮，训练随机采样 p∈{8..48} 一套权重全档位，部署按预算选档。
- **在用模型**：Qwen-VL 系 NaViT 原生动态分辨率同族；机器人端侧 VLA token 预算（SmolVLA 64 / 帧、π0 256 / 帧）。
- **关键点**：**PI-resize**（伪逆 resize）保 token 内积不变，省掉必崩；"大 patch 廉价微调、小 patch 部署"。

**Fast-dLLM / dLLM 服务栈**（NVIDIA, arXiv:2505.22618, ICLR 2026）

- **定位**：解决掩码扩散 LLM 双向注意力无 KV Cache + 并行解码破坏依赖两大瓶颈。
- **收益**：LLaDA 端到端最高 **27.6×**（0.7→19.3 tok/s），精度 −1~2% 内；**Mercury >1000 tok/s**。
