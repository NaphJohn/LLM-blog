### 原理：vLLM #58094 为什么让长上下文 + MTP 接受率归零

本期最值得理解的一条技术解读。

**根因**：target 用 `--hf-overrides` 的 **YaRN 扩展 RoPE** 编码，而 **MTP 草稿模型仍按原生位置编码构建** → 两者位置嵌入错位，超过草稿原生 `max_position_embeddings` 后接受率归零。修复把 **dict 式 hf_overrides 透传到草稿 ModelConfig**。长上下文 + MTP 用户务必核对升级前后接受率。

> 我的判断：这类「配置层与草稿层编码不一致」的 bug 极隐蔽——不报错、不崩溃，只是悄悄把接受率打到 0，直接退化为无投机解码的基线吞吐。如果你在跑 YaRN + MTP，升级前后务必把接受率打出来对比。

## 三、AI论文与产业热点

### 论文核心 · 美团 MR0：回退重做把纠错成本压到「点三次鼠标」

**arXiv:2611.08577（2026-11-05，25 页，代码 / 权重 / RoboDesk 全开源）**

- 一句话定位：面向固定底座桌面操作的 VLA 基座 + 具身 Agent 系统，新意在**数据机制**而非网络结构。
- 核心思想三行：① **1.47 亿**视觉语言样本 + **15,060 小时** / 12 本体轨迹，统一到 **R^20** 末端接口（3 位置 + 6D 旋转 + 1 夹爪，掩码屏蔽 padding）；② 三段式 = FAST 离散 token 预训练 → MMDiT 流匹配中训练 → 真机后训练（SFT / HG-DAgger / RECAP / CFG-DAgger 同起点对比）；③ **Rollback** 保留「被替换的策略片段（I=0）」与「人类替换（I=1）」，CFG-DAgger 直接算 `a_CFG = a₋ + 1.25(a₊ − a₋)`，免价值学习、免 advantage 标注。
- 关键数：RoboTwin **93.6%**，但 RoboDojo 仅 **14.63%**（第 5）→ 桌面专用与通用双臂仍隔一代。
- 影响：DAgger 从「模仿纠正」升级为「**对比纠正**」；数据计价单位由「小时」转向「**负样本密度**」。

### 算子讲解 · Classifier-Free Guidance（CFG，无分类器引导）

- 定位：用同一套权重同时学条件 / 无条件两支，推理时取差外推，把采样往条件方向推得更狠；代价 **2× 前向**。
- 在用模型：SD 1.5（w=7.5）、DiT/SD3（4~7）、GAIA-2（2~20）、π*0.6/RECAP（β=1.75，条件=优势为正）、MR0（γ=1.25，条件=正片段 vs 负片段）。
- 关键两行：`v̂ = v_∅ + w(v_c − v_∅)` 源于贝叶斯 `grad log p(x|c) = grad log p(x) + grad log p(c|x)`；动作侧 γ 只能取 **1.2~1.8**，过冲即超调 / 抖振 / 撞限位。

### 性能优化 · RadixAttention（前缀树 KV 复用 + 缓存感知调度）

- 定位：打掉「多次调用共享同一前缀」的重复 prefill；有效 prefill = `(1−h)·L`。
- 代表工作与收益：最高 **6.4×** 吞吐、Llama-7B 时延最多降 **3.7×**、命中率 **50%~99%**；2026 形态为三级 HiCache + 集群 KV 事件路由。VLA 侧 3Hz 出块、每帧前缀几乎全同，是把控制频率从 3Hz 抬到 5Hz 的前提。
