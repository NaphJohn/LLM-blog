## ★ 今日最值得关注

**REINFORCE Zero：把"异步 RL 数值对齐"从玄学变成可工程化方案。**

两框架本周（周日）稳定版均维持 11-02 收口（vLLM v0.33.0 / SGLang v0.5.23），无新发版；主线在 main 硬化 + SGLang Summit 预热。真正值得盯的是 vLLM 发布的 **REINFORCE Zero（11-06）**——它把"推理服务内核数值一致性"做成了可对齐的工程方案：

1. **异步 RL 稳定了**：rollout 与 trainer **逐位对齐 logprob** + 未裁剪 token 级 IS 修正权重滞后，lag 64 下稳定跑满 **2 万步**、训练步吞吐达同步的 **2.40×** 且**零拒绝**。覆盖 DeepSeek-V4.1-Flash / Kimi K3.1 day-0 / AMD MI355X。
2. **根因量化了**：异步 RL 的 logprob 差被拆成平滑的"权重滞后" + 波动的"内核失配"——不稳定主因是后者（D3 偏离峰值 **442.54×** vs 对齐后 **1.50×**）。

**可执行结论**：做异步 RL / 在线训练的团队，应把"按模型 + 硬件栈逐一建立内核对齐 skill"纳入 rollout 侧改造——代价是 rollout 侧 +2.3%~17% 开销，换来 2.40× 吞吐且零拒绝。

> 值得单独说的一点：又是"**能力在 main，稳定线滞后**"的一天。Kimi K3.1 Pro 的官方 recipe 要求 vLLM 0.34.0+，但稳定线仍是 0.33.0——自托管团队的依赖管理里必须保留一条从 main 拿热修 / 新能力的应急路径，否则要么卡在旧版、要么被"能跑但不对齐"悄悄吃掉训练质量。

### 原理：REINFORCE Zero 把"内核失配"从不可见变量变成可量化开关

本期最值得理解的一条技术解读。

异步 RL 里，rollout（推理服务）与 trainer 跑的不是同一套数值：同样的 prompt，两边算出的 logprob 有差。REINFORCE Zero 把这差值拆成两半：

- **平滑的"权重滞后"**：IS 修正权重本就该滞后（trainer 慢半拍），属于设计内波动；
- **波动的"内核失配"**：推理内核的浮点实现与 trainer 不一致，才是稳定性杀手——D3 偏离峰值 **442.54×**，对齐后降到 **1.50×**。

三步解法：**① 对齐内核**（逐位相同的 logprob）→ **② 未裁剪 token 级 IS 修正滞后**（只修滞后，不动方差）→ **③ 朴素 REINFORCE**（组内均值优势、无价值模型）。代价是每模型 / 硬件栈一套对齐 skill，rollout 侧 +2.3%~17% 开销，换 2.40× 吞吐且零拒绝。

> 我的判断：这是"推理服务和训练同栈"这条老难题的一次工程化结案。它不靠新算法，靠把数值一致性做成可对齐、可验证的工序——对做在线 RLHF / 推理服务一体化的团队，是少有的"照着做就能稳定"的方案。

## 三、AI论文与产业热点

### 论文核心 · Genie 3：通用交互式世界模型

**Google DeepMind, 2025-08-05 博客【具身智能 / 世界模型】**

- 一句话定位：一句话生成 **720p@24fps** 实时可交互世界（一致性数分钟 + 视觉记忆约 1 分钟），把世界模型从视频生成变成**智能体训练基建**。
- 核心思想：① 世界 = 下帧预测器，逐帧自回归 p(x_{t+1}|x_{≤t}, a_{≤t}, c_text)，**无显式 3D**；② 世界记忆约 1 分钟保证复访一致；③ promptable world events 文本第二控制通道制造反事实场景；④ 每帧 ~**42ms** 实时预算。
- 影响：SIMA 在其中训练评测、Waymo 建驾驶世界模型、Project Genie 2026-01-29 开放（单次 60 秒）；印证机器人数据缺口的仿真解法（对应 Thinker-Sim / ApolloWorld / 智元 PhysicalRSI），利好仿真数据合成与算力环节。

### 算子讲解 · SigLIP Sigmoid Loss

**arXiv:2303.15343, ICCV 2023 Oral**：用逐对 sigmoid 替代 CLIP 的 softmax，损失**无需全局归一化**；batch 32k 足够、<16k 区优于 softmax（softmax 需 ~98k 才追平）；SigLiT 4×TPUv4 两天 **84.5%** zero-shot。在用：PaliGemma→π0/π0.5 视觉塔、OpenVLA 双特征、Qwen3-VL 用 SigLIP 2。坑：缩放 / 偏置必须可学习。

### 性能优化 · Alpa 自动并行

**OSDI 2022, arXiv:2201.12020**：算子内 DP + 算子间 ILP 两级自动搜配并行方案；AlphaFold 比人工优化快 **2.4×**；与 ZeRO/TP/SP 正交。坑：MoE 动态负载下静态计划失配。具身 = 小团队训 VLA 的省人力基建。
