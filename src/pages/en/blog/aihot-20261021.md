### Under the Hood: vLLM NIXL GQA Draft-KV Head-Sharding Fix — the root cause of "PD + spec" silent degradation

- **Approach**: under PD disaggregation, the draft (eagle/MTP) KV crosses instances via NIXL; GQA's multi-query heads must be sharded by head dimension. If sharding is mis-aligned, the decode side reassembles wrong head positions → attention is computed wrong but **throws no error**, surfacing as silently degraded output quality.
- **Fix**: align draft-KV sharding by head dimension before NIXL transfer, so the decode side reads a distribution consistent with training.
- **Positioning**: a **must-upgrade correctness fix** for "PD disaggregation + speculative decoding" running together — the same KV-consistency class as OpenInfer/DFlash/DSpark under PD. Before go-live, re-check spec acceptance rate and output quality with lm-eval (same family as the 10-19 Paradigm #41133 "token-swallowing" fix — both are correctness under high concurrency/PD, not throughput).

### Paper Core (DiT · arXiv:2212.09748)

- **One-line positioning**: **the scalable backbone for diffusion** — swapping U-Net for a Transformer and proving diffusion also obeys scaling laws, directly spawning Sora/SD3/FLUX and video world models.
- **Approach**: latent patchify (treat latent as tokens) + **adaLN-Zero** (condition regresses γβ for layer-norm scaling, gating α zero-init for identity start so pretrained distribution is untouched); DiT-XL/2 FID 2.27 SOTA, and **Gflops-FID extrapolates** — double the compute, quality improves predictably.
- **Result / impact**: direct ancestor of Sora/SD3/FLUX and video world models; **π0/GR00T's action expert is essentially a small DiT** (flow-matching) — distillation/cache/quantization all act on it. Isomorphic to this author's VLA line: nail "diffusion backbone obeys scaling laws" first, then talk cost-down on the action expert.

### Operator Deep-Dive: aux-loss-free Load-Balancing Bias (DeepSeek V3/V4)

- **Positioning**: the "zero auxiliary-loss" MoE routing path — **the bias b_i only enters routing selection, the gate value excludes b_i**, updated each step as `b_i −= γ·sign(load_i − mean)`.
- **Key point**: main gradient stays clean (no auxiliary loss distorting the primary task), cleaner than standard aux-loss; GLM shares the family, Qwen3 takes a lightweight aux route. Pitfall = γ too large oscillates, too small corrects slowly; tune against batch load.

### Performance Optimization: Sequence Parallelism / Ring Attention

- **Positioning**: long-sequence training splits activations along the sequence; **Ulysses** shards head-dim communication O(N·d/P), **Ring Attention** ring-passes KV with compute-communication overlap; Ulysses runs 4× longer sequences / +5× throughput vs Megatron-SP, DeepSeek V3 long-sequence throughput 3–4×.
- **Benefit**: the infrastructure for VLA / world-model long-video training — sequence length is the ceiling of embodied long-horizon tasks, and sequence parallelism decides whether a whole demonstration fits in one batch.
