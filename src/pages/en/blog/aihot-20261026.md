## ★ Most Worth Your Attention Today

**SGLang's low-latency megakernel cuts DeepSeek-V4.1-Flash decode latency by another 29%, while llm-d 1.0 closes PD-disaggregation/KV-offload into a production default.**

These are the two most directional threads today, and they point at the same thing: **the inference engine has entered a two-track phase of "control-plane consolidation + kernel-level micro-optimization."**

Three layers of fact:

1. **SGLang Low-Latency**: a megakernel plugin co-built with NVIDIA/AMD pushes V4.1-Flash single-user P90 tok/s from 671 to 928 (GB300, **+1.38×**) / 332→516 (MI355X, **+1.56×**), **decode-layer latency 96.8→68.4 µs (-29.3%)**. The win is not a new algorithm — it is megakernel + compute/communication overlap crushing the small-batch sync overhead.

3. **The same-day contrast**: vLLM is also converging "decision endpoint into the engine" (`/v1/systemone` on by default in v0.32, read as agentic-serving control-plane consolidation).

**Actionable conclusion**: the shortest path to squeeze V4.1-Flash decode latency right now is SGLang's Low-Latency plugin; for scaled PD-disaggregation deployment, llm-d 1.0 has already standardized the routing layer — no need to roll your own.

The most worthwhile technical read of the day — read the two threads together.

In one line — **megakernel + compute/communication overlap crushing small-batch sync overhead**.

## 3. AI Papers + Industry Hotspots

### Paper Core: PINT (arXiv:2610.16355, CASIA / Zhongguancun Academy / Fudan / Tsinghua)

**In one line**: M=32 "predictable intent tokens" act as the single narrow joint between VLM / world model / action head, passing the world model's future prediction one-way to the action expert — no deep fusion needed, "sharing one intent is enough."

- **Core idea**: feeding VLM hidden states straight into the video generation model (VGM) destroys its pretrained generative pathway; PINT uses **M=32 Intent Tokens (d=2560, two linear projections, 10.5M params total)** as the only interface, replacing only VGM's prompt conditioning while keeping its native diffusion path.
- **Mechanism**: VGM runs once on the current frame and caches per-layer K/V; the Action Expert (DiT, 30 layers) reads them one-way per layer (layer l↔l); three losses L_action 1.0 / L_AR 0.1 / L_video 0.1; two stages — S1 freezes VGM to force video gradients through Intent, S2 freezes VLM+Intent so both ends adapt.
- **Impact**: RoboTwin2.0 **Easy 68.6 / Hard 15.5 / Avg 42.1** (8.6× Fast-WAM's 1.8%), LIBERO 98.0, LIBERO-Plus 79.5 (7974/10030); ablation S1-only drops 10.1pp, w/o KV drops 2.7pp. Makes "embodied pretraining" a cost-down path for teams short on data and compute.

### Operator Deep-Dive: MiniMax Sparse Attention (MSA, arXiv:2606.13392)

**Block-sparse attention** — indexer scores → 128-token block maxpool → Top-16 blocks + forced local blocks = a fixed **2048 KV budget per query** (independent of context length).

- **In use**: MiniMax **M3.1-Flash** (428B total / 23B active, 60 layers, `-tp 4`); contrasts with DeepSeek NSA / CSA2 / HCA.
- **Key point**: decode HBM traffic drops to **12.5%** (index/dense = 1/8), 1M-context attention FLOPs down **28.4×**, but real prefill **14.2×** / decode **7.6×** — only **1/3.7** of the FLOPs gain, kernel overhead eats the rest.
- **Gotcha**: block size must equal KV block size; dense fallback is out-of-distribution and loses quality (MSA is a training-time semantic — must be natively sparsely trained).

### Performance Optimization: Tensor Parallelism (TP, Megatron-LM arXiv:1909.08053)

**Column parallelism** (Y_i=X·A_i, zero-communication forward / AllReduce backward) and **row parallelism** (Y=Σ_i X_i·A_i, AllReduce forward) are paired with conjugate f/g, 2 AllReduces forward + 2 backward per layer, ring sends/receives 2(p−1)/p·N·bytes per rank.

- **Example**: M3.1-Flash official vLLM recipe `-tp 4 --block-size 128 --kv-cache-dtype nvfp4`, 428B NVFP4≈214GB → 54GB per GPU across 4.
- **Gain** = VRAM roughly divided by TP degree; **gotcha** = cross-machine TP stalls on Ethernet, and GQA KV heads must be divisible by TP degree (M3.1 has only 4 KV heads → **TP≤4**, tighter than the previous gen).
