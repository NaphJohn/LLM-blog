### Under the Hood: vLLM EPD Multimodal Disaggregated Serving — pulling the "heavy encoder" off the hot path

- **Approach**: on top of PD disaggregation, split multimodal Encode (vision/audio encoder) into its own stage/pool (EPD = Encode-Prefill-Decode). Encoding / prefill / decode can scale independently — the heavy ViT/audio tower no longer competes with the LLM for the same prefill/decode GPU; this round #62573 adds metadata-only audio-in-video support, further decoupling multimodal metadata from the token stream.
- **Impact**: for long-context multimodal deployments (Step-3-VL / Step-Video / audio-in-video), first-token and throughput are no longer dragged down by encoder peaks — the encode pool can scale out and the decode pool can scale in independently.
- **Positioning**: same lineage as "strip Python from the hot path (MRV2 / Rust core)" — isolate non-LLM compute from the inference hot path to lift GPU utilization.

## 3. AI Papers & Industry Hotspots

### Paper Core (MemoryVLA · arXiv:2508.19236)

- **One-line positioning**: **a memory framework for long-horizon robot manipulation** — robot manipulation is non-Markovian, and mainstream VLA's frame-by-frame amnesia causes repetition/skipping; MemoryVLA keeps "context" with a dual-memory system.
- **Approach**: **Cognition-Memory-Action** — VLM encodes perception + cognition tokens (working memory) → **PCMB memory bank** (detail + semantic) retrieval / gated fusion / consolidation → diffusion action expert; the memory bank keeps the agent from losing prior context across a long sequence.
- **Result / impact**: LIBERO 96.5%, Bridge +14.6, real-robot 84%, long-horizon +26, already integrated into Dexbotic. Memory becomes the **third competitive dimension** for VLA after "see it" and "move it right" — directly hitting real scenarios like long-horizon assembly and multi-step cooking.

### Operator Deep-Dive: FiLM Conditional Modulation

- **Positioning**: condition information modulates features channel-wise via γ/β, **O(N) replacing cross-attention** — lightly fuses task/language/embodiment conditions into visual features; RT-1 language conditioning, RT-X embodiment embedding, **DiT adaLN-Zero (= FiLM + zero-init)**, and MemoryVLA's gated variant all use it.
- **Key point**: **γ zero-init for identity start** — does not break the pretrained distribution at the start of training; the network learns condition strength itself.

### Performance Optimization: Hot/Cold Weight Separation / Sparse Activation (PowerInfer / Apple LLM in a Flash)

- **Positioning**: activations follow a power-law sparsity — **hot weights stay resident on GPU, cold weights are asynchronously prefetched on demand**, compressing DRAM footprint to 1/4~1/10 and accelerating first-token by 4~25×.
- **Benefit**: one of the "three essentials" for embodied VLA on-device deployment (quantization + speculation + hot/cold separation), directly deciding whether a large model can run on the limited memory of a vehicle/robot body.
