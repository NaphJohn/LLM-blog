### Under the Hood: Why #58094 Drove Long-Context + MTP Acceptance to Zero

The most worthwhile technical read of the day.

**Root cause**: the target uses `--hf-overrides` for **YaRN-extended RoPE** encoding, but the **MTP draft model is still built with native positional encoding** → the two position embeddings misalign, and once past the draft's native `max_position_embeddings` the acceptance rate goes to zero. The fix propagates the **dict-style hf_overrides down to the draft ModelConfig**. Long-context + MTP users must compare acceptance before and after upgrading.

> My read: this class of "config-layer vs draft-layer encoding mismatch" bug is insidious — no error, no crash, just silently drives acceptance to 0 and degrades to the no-speculation baseline throughput. If you run YaRN + MTP, print and compare the acceptance rate before and after the upgrade.

## 3. AI Papers & Industry Hotspots

### Paper Core · Meituan MR0: Rollback Turns Error-Correction Cost Into "Three Mouse Clicks"

**arXiv:2611.08577 (2026-11-05, 25 pages, code / weights / RoboDesk fully open)**

- One-liner: a VLA base + embodied agent system for fixed-base desktop manipulation, where the novelty is the **data mechanism** rather than the network structure.
- Core idea, three lines: ① **147M** vision-language samples + **15,060 hours** / 12-embodiment trajectories, unified to an **R^20** end-effector interface (3 position + 6D rotation + 1 gripper, masked padding); ② three-stage = FAST discrete-token pretrain → MMDiT flow-matching midtrain → real-robot posttrain (SFT / HG-DAgger / RECAP / CFG-DAgger compared from the same starting point); ③ **Rollback** keeps both the "replaced policy fragment (I=0)" and the "human replacement (I=1)", and CFG-DAgger directly computes `a_CFG = a₋ + 1.25(a₊ − a₋)` — no value learning, no advantage labeling.
- Key numbers: RoboTwin **93.6%**, but RoboDojo only **14.63%** (5th) → desktop-specialized and general dual-arm are still a generation apart.
- Impact: DAgger upgrades from "imitation correction" to "**contrastive correction**"; the unit of data accounting shifts from "hours" to "**negative-sample density**."

### Operator Note · Classifier-Free Guidance (CFG, classifier-free guidance)

- Positioning: one set of weights learns both the conditional and unconditional branches; at inference take the difference and extrapolate, pushing sampling harder toward the conditional — at the cost of **2× forward passes**.
- In-use models: SD 1.5 (w=7.5), DiT/SD3 (4~7), GAIA-2 (2~20), π*0.6/RECAP (β=1.75, condition = positive advantage), MR0 (γ=1.25, condition = positive vs negative fragment).
- Key two lines: `v̂ = v_∅ + w(v_c − v_∅)` derives from Bayes `grad log p(x|c) = grad log p(x) + grad log p(c|x)`; on the action side γ must stay in **1.2~1.8** — overshoot causes overcorrection / jitter / hitting limits.

### Performance Optimization · RadixAttention (radix-tree KV reuse + cache-aware scheduling)

- Positioning: kills the repeated prefill of "multiple calls sharing the same prefix"; effective prefill = `(1−h)·L`.
- Flagship work and gains: up to **6.4×** throughput, Llama-7B latency down up to **3.7×**, hit rate **50%~99%**; the 2026 form is 3-tier HiCache + cluster-wide KV event routing. On the VLA side, 3Hz block emission with near-identical prefixes per frame is the precondition for lifting the control rate from 3Hz to 5Hz.
