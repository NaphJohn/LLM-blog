## ★ Most Worth Your Attention Today

**SGLang's CVE-2026-111391: a CVSS 9.2 dumper eval() injection with no patch, and v0.5.23 isn't fixed either.**

This is the only item today that will **turn your production service into a remote-execution entry point** — and the trouble isn't the vulnerability itself, it is the **reachability of the fix**.

Three layers of fact:

1. **Symptom**: an `eval()` injection in SGLang's `dumper/configure` (CVE-2026-111391, CVSS **9.2**); anyone who can reach the dumper service gets remote code execution. Not mild privilege escalation — straight RCE.
2. **Fix**: the fix PR **#44205 was closed without merging**; the latest stable **v0.5.23 is also unfixed**.
3. **Blast radius**: **0.5.10–0.5.22 are all affected**, plus the unfixed v0.5.23 — which covers the vast majority of production deployments today.

**Actionable conclusion**: until an official patch ships, the only defense is the deployment-side triple — **leave `DUMPER_SERVER_PORT` unset + set `admin_api_key` + restrict the port to loopback / private network only**. This CVE matches the Summit's "harden first, scale later" rhythm: this week's main line is hardening, not new features.

> Worth saying separately: a fix PR that got closed, with no patch reachable across multiple stable releases, deserves more caution than the bug itself. It means your dependency-management strategy must include an **emergency path for building from main** — not because you want to chase the bleeding edge, but because you need an escape hatch between "vulnerability disclosed" and "next tag."

### Under the Hood: Kimi K3.1 Pro's DSA Sparse Attention

The most worthwhile technical read of the day.

Each layer hangs a **lightweight Indexer beside the MLA** — **FP8 key + 32-head scoring, keeping only top-2048**. Engineering-wise it packs **MLA latent + Indexer keys + KDA state into the same paged cache** (transferable as one block under PD disaggregation); **token-sharded prefill** makes TTFT for 340K tokens / 8×GB300 **1.69× faster** than head-sharded; **DCP8 holds 7.2× the KV of TP8**.

> This mechanism shares lineage with **Step 5 Preview's sparse attention (Indexer + Region)**. Understand K3.1 Pro early and you essentially understand Step 5's long-context deployment shape — the best "pre-study investment" of the week.

## 3. AI Papers & Industry Hotspots

### Core Papers

**Hi Robot** (Physical Intelligence, arXiv:2502.19417, CoRL 2025) 【Embodied AI】

- **One-line positioning**: a hierarchical interactive VLA — a high-level **PaliGemma-3B VLM at ~1Hz** emits low-level language commands, a low-level **π0 at 50Hz** executes action chunks.
- **Core idea**: System2 / System1 split learning "what to say" and "how to do"; ~1000 teleop demos cut into 1–3s skill segments, a teacher VLM **hindsight-reverses** user prompts / interruptions into synthetic supervision (cuts synthetic-data **IA by −46%**).
- **Impact**: same paradigm as π0.5 / Helix / DriveVLM; hindsight-reversed supervision = a general fix for scarce human-robot-interaction data; vs GPT-4o high-level **IA +40%**, vs flat VLA **IA +34% / TP +19%**.

**FlexiViT** (Google, arXiv:2212.08013, CVPR 2023)

- **Positioning**: patch size = the ViT accuracy / compute knob; train once with randomly sampled p∈{8..48} and you cover all tiers, pick a tier at deploy time by budget.
- **In active use**: Qwen-VL's NaViT native dynamic resolution is the same family; embodied edge VLA token budgets (SmolVLA 64 / frame, π0 256 / frame).
- **Key point**: **PI-resize** (pseudo-inverse resize) preserves token inner products and avoids the must-crash case; "big patch cheap finetune, small patch deploy."

**Fast-dLLM / dLLM serving stack** (NVIDIA, arXiv:2505.22618, ICLR 2026)

- **Positioning**: solves the two bottlenecks of masked-diffusion LLMs — bidirectional attention with no KV Cache, and parallel decoding that breaks dependencies.
- **Gains**: LLaDA end-to-end up to **27.6×** (0.7→19.3 tok/s), within −1~2% accuracy; **Mercury >1000 tok/s**.
