- **Results (self-reported)**: no robot pretrain LIBERO 98.3%, CALVIN task length 3.73, real success 6.7%→37.8%.

### Operator Deep-Dive: Token Merging (ToMe · arXiv:2210.09461)

- **Positioning**: **bipartite soft-match merges similar tokens per layer**, size-weighted average `z_m=(s_i·z_i+s_j·z_j)/(s_i+s_j)`; facebookresearch/ToMe patches into timm/MAE/SWAG, ToMeSD accelerates Stable Diffusion.
- **Key point**: versus pruning it "merges" not "discards", preserving information better; **Qwen3-VL / DeepSeek-VL2 / InternVL / MiniMax-VL / GLM-4.5V vision-token compression belong to the same lineage**; ViT-L image 2× throughput, video 2.2×, accuracy down only 0.2~0.3%, attention compute ~1/4.
