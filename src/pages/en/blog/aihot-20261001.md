### Paper Core (Skild S1 · In-Context Learning for Robotics)

- **One-line positioning**: ports the LLM "in-context learning" paradigm into robotics — using **video demos** instead of text instructions, training the robot policy as a **meta-learner** so that a single video evokes the ability to execute a novel task, no per-task fine-tuning needed.
- **Core approach**: pretraining mixes **teleoperation / UMI glove / first-person video / simulation** four data types; internal unseen-task benchmark **66% step success** (assisted) vs **9% for a language-prompt VLA**; one video ≈ **380 post-training episodes** — the data efficiency of video prompts far exceeds per-task training.
- **Impact**: if data scale keeps growing, the robotics deployment economic model may shift from "**per-task trained expert**" to "**general brain + video prompt**", analogous to LLM going from BERT to GPT-3.
- **Limitation**: no public weights / paper / API, data is Skild's internal test, demos are curated, and the **66% is an assisted per-step success rate** — treat it as a route signal, not a production benchmark.

### Operator Deep-Dive: SoftMoE (soft top-k routing, arXiv:2606.17952)

- **Positioning**: replaces hard top-k with **LapSum soft top-k** so that **routing becomes gradient-optimizable** — the number of activated experts per layer `k_l = K·softmax(α_l)` becomes a learnable parameter, and routing is no longer discrete and non-differentiable.
- **In use / related**: directly related to the **DeepSeek V4 / Qwen3-MoE / MiniMax dense MoE** routes; **edge VLA** can use it to dynamically reduce activated experts and cut latency (activated-expert count becomes learnable per layer rather than a fixed K).

### Performance Optimization: SonicMoE (MoE IO/Tile-aware acceleration, arXiv:2512.14080)

- **Positioning**: targets the **activation-memory bloat and GEMM padding waste** of **high-granularity + high-sparsity MoE** — memory-efficient backward propagation **−45%**, **64 H100 daily training of 213B tokens**, Blackwell forward **+25%** / backward **+15%**.
- **Same family**: in the same family as **MegaBlocks / DeepGEMM / SGLang / vLLM fused MoE kernels**, **benefiting MoE VLA edge deployment** (the memory and compute waste of sparse activation is leveled out at the Tile level).
