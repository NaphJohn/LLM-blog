### Under the Hood: SGLang #39627 Prefix Cache Sunk to Rust Core (free latency cut under high concurrency)

- **Approach**: sink the prefix cache from the Python layer into the **scheduler's Rust core** — cache-hit **query / insert / evict** share the process with scheduling, which under **GIL contention** was a hidden TTFT bottleneck at high QPS; after sinking, high-concurrency prefix-reuse load gets **free latency reduction**.
- **Same trend**: same direction as **vLLM sinking its scheduling core into Rust/C++** — stripping Python from the hot path of inference engines is now consensus; the Rust core = latency determinism under high concurrency.

> My read: the prefix cache looks like a "store the hit" module, but its query/evict in the Python layer contends for the GIL with scheduling and actually drags TTFT at high QPS. SGLang moving it into the Rust core erases that hidden bottleneck outright — the hardest item in v0.5.21's "free" dividend, not decoration.

### Operator Deep-Dive: DyT (Dynamic Tanh, Transformers without Normalization, Zhu et al., CVPR 2025, arXiv:2503.10622)

- **Positioning**: replaces LayerNorm/RMSNorm with a **learnable tanh curve** — formula **DyT(x)=γ·tanh(αx)+β**; **LLaMA 8B training −42.2%, inference −52.4%**, validated across ViT/MAE/DiT/LLaMA, a candidate for cutting the norm-layer cost in on-device VLA.
- **Significance**: the norm layer is not a "free lunch" — DyT proves it can be dropped wholesale, a direct layer-cost cut for latency-sensitive on-device / whole-body VLA.

### Performance Optimization: AdaEAGLE (adaptive speculative decoding, SJTU, arXiv:2412.18910)

- **Positioning**: adds a lightweight **draft-length predictor LDLP** to **EAGLE**, deciding how many tokens to draft per step dynamically, **1.62× lossless**; orthogonal to **JetSpec (method layer), DSpark (system layer), SpecDec++ (threshold MDP)**, together serving VLA on-device low-latency control.
- **Same family**: in the same big direction as this author's OpenInfer/DFlash candidate selector — "speculative-decode refinement"; how the draft structure is set and adapted tracks real acceptance length better than a fixed K.
